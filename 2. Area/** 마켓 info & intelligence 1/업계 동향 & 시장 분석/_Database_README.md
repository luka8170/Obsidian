# Korean Shipowners Database

## Database Structure

This database tracks Korean shipping companies with focus on:
- Company profiles and fleet information
- Newbuilding orderbook
- Market updates and intelligence
- Bureau Veritas business opportunities

## Database Sheets

### 1. Companies
Master list of Korean shipowners with basic information:
- Company name, group affiliation
- Main business type
- Fleet size and composition
- Global ranking

### 2. Fleet
Detailed vessel information for each company:
- Vessel names and types
- Size (TEU/DWT), build year
- Flag, operator
- Classification society

### 3. Orderbook
Newbuilding orders tracking:
- Vessel specifications
- Shipyard and country
- Contract details and delivery dates
- Classification status

### 4. Updates_Log
Chronological record of company updates:
- Date and update type
- Description and source
- Impact assessment

### 5. BV_Business
Business opportunity tracking for Bureau Veritas:
- Project type and vessel count
- Status and opportunity level
- Next actions and contacts
- Additional notes
