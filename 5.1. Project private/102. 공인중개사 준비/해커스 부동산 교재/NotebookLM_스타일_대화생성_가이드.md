## 🎙️ NotebookLM이란?

**Google의 AI 도구:**
- 문서 업로드 → AI가 팟캐스트 스타일 대화 생성
- 2명의 진행자가 자연스럽게 대화
- 복잡한 내용을 쉽게 설명
- 음성으로 출력

**예시:**
```
보세사 교재 PDF 업로드
↓
AI가 10분짜리 대화 생성
↓
"오늘은 보세사에 대해 이야기해볼게요"
"네, 보세사는 보세구역을 관리하는 전문가죠"
"맞아요, 구체적으로 어떤 일을 하나요?"
```

## 🔧 NotebookLM 사용법 (무료)

### 1. 접속

**URL:** https://notebooklm.google.com

**요구사항:**
- Google 계정 (Gmail)
- 크롬 브라우저 권장
- 무료!

### 2. 문서 업로드

**지원 파일:**
- PDF
- Google Docs
- 텍스트 파일
- 웹사이트 URL
- YouTube 링크

**예시 (보세사/관세사 준비):**
```
보세사 준비:
- 보세사 기본서 PDF 업로드
- 관세법 요약본 업로드
- 관세청 공고문 URL 입력

관세사 준비:
- 관세사 교재 PDF
- 합격 수기 문서
```

### 3. Audio Overview 생성

**버튼 클릭:**
```
우측 상단 "Generate" 클릭
→ "Audio Overview" 선택
→ 5-10분 대기
→ 팟캐스트 스타일 대화 완성
```

**결과:**
- 10-15분 분량
- 2명 진행자 대화
- 영어 (현재는 영어만)
- MP3 다운로드 가능

## 💎 대안 1: Claude (현재 사용 중)

### 방법: Prompt로 대화 생성

**Step 1: 문서 업로드**
```
Claude에게:
"이 보세사 교재 PDF를 보고 
팟캐스트 스타일 대화를 만들어줘"

[PDF 첨부]
```

**Step 2: 대화 스타일 지정**
```
2명의 진행자:
- 진행자 A: 초보자 (질문하는 역할)
- 진행자 B: 전문가 (설명하는 역할)

대화 형식:
- 자연스러운 한국어
- 10분 분량 (약 2,500단어)
- 쉬운 설명 + 예시
```

### Prompt 템플릿

```
다음 문서를 바탕으로 한국어 팟캐스트 대화를 만들어주세요:

[문서 내용 또는 첨부]

요구사항:
1. 2명의 진행자 (초보자 A, 전문가 B)
2. 10분 분량 (2,500단어)
3. 자연스러운 대화체
4. 어려운 용어는 쉽게 풀어서 설명
5. 구체적 예시 포함
6. 유머 가끔 섞기

시작 멘트: "안녕하세요, 오늘은 [주제]에 대해 이야기해볼게요"
```

**장점:**
- ✅ 한국어
- ✅ 무료 (Claude 사용 범위 내)
- ✅ 커스터마이징 자유
- ✅ 즉시 생성

**단점:**
- ❌ 음성 없음 (텍스트만)
- ❌ 직접 읽어야 함

## 💎 대안 2: ChatGPT + TTS

### Step 1: ChatGPT로 대화 생성

**ChatGPT Plus (유료):**
- GPT-4 사용
- 문서 업로드
- 대화 생성 요청

**무료 버전:**
- 텍스트 복사 붙여넣기
- 대화 생성

### Step 2: 음성 변환

**A. 네이버 Clova (한국어)**
- URL: https://clovadubbing.naver.com
- 텍스트 입력 → 한국어 음성 생성
- 무료 체험 가능

**B. TYPECAST (한국어) - 추천**
- URL: https://typecast.ai
- 가격: 월 9,900원
- 가장 자연스러운 한국어
- 여러 목소리 선택
- 감정 조절 가능

**사용법:**
1. 회원가입
2. 대화문 입력
3. 진행자 A: 여성 목소리
4. 진행자 B: 남성 목소리
5. 각각 생성 → MP3 다운로드

## 💎 대안 3: Obsidian + Claude 워크플로우

### 완벽한 통합 시스템

**Step 1: Obsidian에 문서 정리**
```
보세사 공부 노트:
├─ 관세법 요약
├─ 관세율표 정리
├─ 내국소비세법 핵심
└─ 기출문제 오답
```

**Step 2: Claude에게 대화 생성 요청**
```
"내 Obsidian 노트를 바탕으로 
복습용 팟캐스트 대화 만들어줘"

[노트 복사 붙여넣기]
```

**Step 3: 생성된 대화를 Obsidian에 저장**
```
새 노트 생성:
"보세사_복습_팟캐스트_EP1.md"

내용:
[Claude가 생성한 대화]

태그:
#보세사 #복습 #팟캐스트
```

**Step 4: 음성으로 듣기 (선택)**
- Option A: 직접 읽기
- Option B: TTS 변환 (Clova/TYPECAST)
- Option C: 그냥 텍스트로 복습

## 💡 Pro Tips

### 좋은 대화 생성 포인트

✅ 구체적 예시 포함
✅ 진행자 캐릭터 명확
✅ 단계적 설명
✅ 유머 적절히
✅ 질문-답변 리듬

### 나쁜 예

❌ 너무 길고 지루함
❌ 전문 용어 남발
❌ 일방적 설명
❌ 캐릭터 구분 안 됨

### TYPECAST 설정 팁

```
진행자 A: 
- 목소리: "지은" (여성, 밝음)
- 속도: 110%
- 톤: 친근함

진행자 B:
- 목소리: "준영" (남성, 안정적)
- 속도: 100%
- 톤: 전문가
```
