# SOP: 미팅 음성메모 → 영업 산출물 자동화
**작성**: 2026-04-05 | **작성자**: Claude (한상진 이사 업무용)
**소요시간**: 약 10~15분 | **난이도**: ★☆☆☆☆

---

## 언제 쓰는가

선주사 미팅 후 음성 메모(m4a/mp3/wav)가 있을 때.
→ 3가지 산출물을 자동으로 생성:
1. **미팅 보고서** (Obsidian 저장)
2. **후속 이메일 초안** (Obsidian 저장, 바로 발송 가능)
3. **스킬 파일 업데이트** (다음 영업에 반영)

---

## 준비물

- 미팅 음성 파일 (m4a 권장, iPhone 기본 녹음앱)
- NotebookLM 접속 (notebooklm.google.com) — Google 계정 로그인 상태
- Claude 대화창 (이 파일을 읽힌 상태)

---

## Step-by-Step

### Step 1 — NotebookLM 새 노트북 만들기 (2분)
1. [notebooklm.google.com](https://notebooklm.google.com) 접속
2. **"새 노트 만들기"** 클릭
3. 팝업에서 **"파일 업로드"** 클릭 → 음성 파일 선택
4. 노트북 제목이 자동 생성될 때까지 대기 (약 1~2분)
5. **채팅 탭**으로 이동

### Step 2 — NotebookLM 분석 질의 (복사해서 붙여넣기)

아래 프롬프트를 채팅창에 붙여넣고 전송:

```
이 미팅 녹음을 분석해서 다음을 정리해줘:
1) [선주사명] 측이 언급한 주요 관심사와 Pain Point
2) BV에 대한 반응이나 코멘트
3) 다음 액션 아이템 또는 후속 요청사항
4) 선급 선택 관련 의사결정 힌트
구체적으로 인용해서 답변해줘.
```

### Step 3 — Claude에게 산출물 생성 요청 (1분)

NotebookLM 답변이 나오면, **이 대화창**으로 돌아와서:

```
[선주사명] NotebookLM 분석 결과야:

[NotebookLM 답변 전체 복사·붙여넣기]

이걸 바탕으로:
1. Obsidian에 미팅 보고서 저장 (1. Project/[선주사명]/)
2. 후속 이메일 초안 작성·저장
3. SKILL_KoreanShipownerOutreach.md 해당 선주사 항목 업데이트
```

### Step 4 — 확인 (30초)
- Obsidian에서 파일 2개 생성 확인
- 이메일 초안 검토 후 바로 발송

---

## 선주사별 NotebookLM 분석 추가 질문 (선택)

필요시 Step 2 이후 추가로 질의:

**신조 관련:**
```
신조 발주 일정, 조선소, 척수에 대해 언급된 내용을 정리해줘.
```

**경쟁사 관련:**
```
KR, DNV, LR 등 다른 선급에 대한 언급이 있었는지 정리해줘.
```

**기술 관련:**
```
친환경 기술, 신기술 도입 관련 언급된 내용을 정리해줘.
```
