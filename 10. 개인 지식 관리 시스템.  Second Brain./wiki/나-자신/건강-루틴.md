# 건강 루틴

> 출처: 헬스조선·중앙일보·조선일보 아티클 모음 | 핵심: **혈당·뇌건강·항노화 습관**

## 핵심 인사이트

### 1. 혈당 관리 (혈당 스파이크 예방)
- **식후 30분 혈당 스파이크** 주의: 삼각김밥+컵라면 조합 같은 정제탄수화물 과부하 금지
- 약사 추천 공복 루틴 3가지 조합: 혈당 스파이크 완화에 효과
- 혈당·혈압·체중 중 하나라도 이상 → 암 위험 지름길 (대사증후군 경고)
- **식사 순서**: 채소 → 단백질 → 탄수화물 순으로 먹기

### 2. 뇌 건강 & 항노화
- **미세플라스틱**: 간·콩팥보다 뇌에 더 많이 축적 → 치매·뇌졸중 위험
  - 대응: 일회용 플라스틱 용기 줄이기, 가열 플라스틱 금지
- **90세 경제학자 비결**: 옷도 음식도 "낭비 없이 꾸준히" → 절제와 규칙성
- **대장암 예방**: 매일 섭취하는 특정 음식/음료 효과 (발효식품, 식이섬유)

### 3. 슈퍼푸드 채소
- 나물로 착각하는 채소: 혈압·시력·치매 예방에 효과 (→ 적색·자색 채소류)
- 붉은색 채소 아침 공복 섭취: 혈류 개선 효과
- **비트, 적양파, 자색고구마** 계열 → 항산화·혈압 관리

### 영양제에 대한 핵심 정리

**"건강한 아이는 비타민D 하나면 된다"**

- 영양제 시장: 전 세계 영유아 건기식 2023년 67억 달러, 2019년 대비 43% 성장 → **불안 마케팅이 시장을 키움**
- 약보다 안전하다는 건 오해 — 건기식은 의약품보다 안전성 검증 기간·규모가 훨씬 작음
- 식약처 이상 사례 신고 연간 3000건+ (대부분 소화불량·가려움)

**유산균 숫자 마케팅 주의**
- 투입균수(100억 마리) ≠ 보장균수(소비기한까지 살아있는 균) → 보장균수(CFU) 확인
- 숫자보다 **균주의 질**이 핵심: LGG, BB-12처럼 연구 논문 1000편+ 검증된 균주 선택
- 발효식품(요구르트·김치·청국장) 섭취가 유산균 보충제보다 장 환경 개선에 더 효과적

**성장호르몬 주사 진실**
- 의학적 원인(성장호르몬결핍증, 터너증후군 등) 없으면 효과 미미: 연간 1000만원 vs. 최종 키 1~2cm
- **진짜 성장 치트키**: 수면(성장호르몬 분비 폭발) + 고강도 운동(평소 대비 10~20배 분비) + 균형 식단
- 성장주사는 아이에게 "지금의 나는 부족하다"는 메시지를 내면화시킬 수 있음

**실용 요약**
| 항목 | 결론 |
|------|------|
| 영양제 기본 | 건강한 아이는 비타민D 1가지면 충분 |
| 유산균 | 보장균수(CFU) + LGG/BB-12 균주 확인 |
| 홍삼 | 굳이 불필요 (밖에서 1시간 뛰는 것이 더 효과적) |
| 성장 | 잘 자고 + 땀 흘려 놀고 + 잘 먹기 |
| 성장주사 | 의학적 원인 없으면 비용 대비 효과 낮음 |
