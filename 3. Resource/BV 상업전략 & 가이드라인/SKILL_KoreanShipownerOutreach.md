## 2. 한국 선주사 의사결정 구조 ★ NotebookLM 32개 소스 기반 업그레이드

### 2-1. 선급 선택 5대 기준 (실제 조사 결과 기반, 우선순위 순)

1. **Rule Practicality & Surveyor Competency** (해무팀 주도)
   - 기술 부서가 실질적 게이트키퍼 역할
   - 선급 규칙의 현장 적용 가능성 + 현장 검사관의 전문성을 집중 평가
   - → **BV 대응**: 검사관 직접 소개, 한국어 대응 가능 surveyor 강조

2. **Cost & Financial Predictability** (재무팀 주도)
   - OPEX 장기 예측 가능성이 핵심
   - FYF/Block Fee로 연간 수수료 변동 리스크 제거
   - PE 백업 선주사(예: Hahn & Co.-owned SK Shipping)는 EBITDA 안정성 요구
   - → **BV 대응**: FYF + 기존 선대 TOC 번들 패키지 선제 제안

3. **ESG Alignment & Long-Term Partnership** (CEO/이사회 주도)
   - BV의 SMART notation, Cyber Security 등 ESG 등급 향상에 직결되는 인증 강조
   - 탈탄소화 전략과 연계된 장기 파트너십 어필
   - → **BV 대응**: Augmented Ship (Group 3) SMART notation 소개

4. **Shipyard Compatibility & Track Record** (신조 부서 주도)
   - 조선소 선호 설계와의 정합성, 조달 비용 영향, 건조 일정 준수 이력 평가
   - → **BV 대응**: HD현대삼호/한화오션/삼성중공업 내 BV 현장 실적 제시

5. **Speed of Response & Early Technical Advice** (전 부서 공통)
   - 설계 초기 단계에서의 빠른 기술 조언이 신뢰 구축의 핵심
   - 전체 프로젝트 비용 절감에 직접 기여하는 것으로 인식됨
   - → **BV 대응**: Plan Approval 속도 + KPO 기술팀 조기 투입 강조

### 2-2. FYF/Block Fee Agreement가 의사결정에 미치는 구체적 영향

**왜 FYF가 강력한 영업 도구인가:**

| 효과 | 설명 |
|------|------|
| **OPEX 고정화** | 5년 선급 수수료를 단일 고정비로 전환 → 예산 예측 가능성 확보 |
| **단일 인보이스** | 개별 검사별 청구 → 연간 통합 청구로 단순화 (Pan Ocean, HMM 선호) |
| **Fleet Volume Discount** | 척수가 늘수록 척당 단가 하락 → 신조 추가 시 자동 인센티브 |
| **Class Buy-Out 전략** | 기존 선대 TOC 패키지를 저가 제공 → 신조 계약 선점 |

> **핵심 전술**: 신조 문의 접수 즉시, 기존 선대 + 신조 통합 Block Fee 패키지를 
> 선제적으로 제안하면 경쟁사가 파고들기 매우 어렵다.

### 2-3. 경쟁사 대비 BV 차별화 포인트 (32개 소스 분석)

| 선급 | 강점 | BV 대응 메시지 |
|------|------|----------------|
| **KR** | 국내 Flag 행정 동등성, HMM·Sinokor 원자력 추진 동맹, HD현대 AI설계 공동개발 | "BV의 글로벌 Port State 수용성 + RO Authority + 국제 금융기관 신뢰도는 KR이 대체 불가" |
| **DNV** | R&D 투자(매출 5%), Future-Ready notation, 디지털 규제 영향 예측 서비스 | "BV의 LNG 시장점유율 30%·SMART notation 실적이 실질적 운항 리스크 감소에 더 직접적" |
| **LR** | 탈탄소화 허브, 바이오연료 전환 컨설팅 | "BV의 cryogenic 기술(GTT sloshing, BOG mgmt) + Augmented Ship이 LNGC에 최적" |

**BV 고유 강점 (경쟁사 없음):**
- LNG bunkering 선급 세계 1위 (30% market share)
- GTT 멤브레인 시스템 sloshing analysis 전문성
- Augmented Ship (Group 3) SMART notation — 실시간 육상 모니터링
- 메탄올 bunkering vessel 세계 최초 선급

### 2-4. 신조 선급 선점을 위한 최적 타이밍 ★ 핵심 인사이트

```
[발주 루머] → [Inquiry 접수] → [84시간 결정] → [LOI 서명] → [조선소 계약]
      ↑               ↑                                ↑
  가장 이상적        마지막 기회                   이미 늦음
  접촉 시점       (notation 지정)              (변경 시 비용·일정 타격)
```

**84시간 룰 (가장 중요한 타이밍 법칙):**
- 선주가 조선소에 Inquiry를 제출하면, 조선소는 **3~4일(84시간)** 내에 프로젝트 용량과 의무 선급 notation을 평가
- 이 창 안에 BV notation이 Inquiry에 명시되지 않으면 기본 가격 영향 불가
- **LOI 서명 후에는 변경이 거의 불가능** — 조선소가 비용·일정 이유로 강하게 저항

**사전 접촉 전략 (Proactive Technical Consultancy):**
1. 조선소 발주 Tender 시작 **이전**에 선주에게 "Green & Smart Ship" 스펙 정의 지원
2. BV notation을 Inquiry에 자연스럽게 포함시키도록 유도
3. 동시에 기존 선대 Block Fee 번들 제안으로 전환 비용을 최소화

## 3. 아웃리치 작성 프로세스

### Step 1: 인풋 확인
- **선주사명** (필수)
- **목적** (필수) — 신조 선급, CAC/TOC 이적, FYF 갱신, 미팅 후속
- **트리거/시그널** — 발주 루머, LOI 소식, 임원 변경, 뉴스
- **선종** (있으면) — VLCC, LNGC, Bulk, Feeder Container 등
- **언어** — 한국어 / 영어 / 혼용
- **채널** — 이메일 / KakaoTalk / 미팅 자료

### Step 2: 시그널 강도 판단
```
HIGH  → 조선소 LOI·계약 서명, Inquiry 제출 직전/직후 → 즉각 FYF 번들 제안
MID   → 업계 루머, 슬롯 문의, 임원 미팅 요청 → Technical Consultancy 선제 접촉
LOW   → 뉴스, 운임 시황 변화 → 관계 유지 방문 + BV 기술 브리핑
```

### Step 3: 아웃리치 3원칙
1. **Signal-First** — 첫 문장은 구체적 사실/시그널로 시작
2. **One Ask** — 요청은 하나만
3. **Pain → Value** — 선주사 과제와 BV 솔루션을 1:1로 연결
