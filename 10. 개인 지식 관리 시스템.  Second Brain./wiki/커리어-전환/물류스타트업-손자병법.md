# 물류 스타트업 전략 — 손자병법 13편

> "지피지기 백전불태(知彼知己 百戰不殆)" — 적을 알고 나를 알면 백 번 싸워도 위태롭지 않다

## 핵심 전략 3원칙

### 1. 지피지기(知彼知己) — 정보 우위
- 경쟁사 분석 + 고객 Pain Point 정기 업데이트
- 운임 시장 트렌드 데이터베이스 구축

### 2. 병귀승 불귀구(兵貴勝 不貴久) — 신속한 승부
- 3개월 MVP → 6개월 정식 론칭 → 12개월 시장 검증
- 빠른 학습이 유일한 경쟁 전략

### 3. 부전이굴인지병(不戰而屈人之兵) — 경쟁 회피
- 기자재 업계 특화로 대형 포워더와 직접 경쟁 회피
- 25년 네트워크로 진입 장벽 구축

## 손자병법 기반 시장 분석

| 편 | 핵심 원리 | 물류 스타트업 적용 |
|----|---------|----------------|
| 시계(始計) | 도·천·지·장·법 5요소 | 도메인 전문성(장) + 디지털 전환 타이밍(천) |
| 모공(謀攻) | 싸우지 않고 이기기 | 기자재 틈새 → 대형 포워더 경쟁 회피 |
| 군형(軍形) | 불패 기반 구축 | 핵심 고객 장기계약 + 데이터 자산 축적 |
| 허실(虛實) | 약점 공략 | 대형 포워더 약점(개인화 부족) 공략 |
| 용간(用間) | 정보 수집 | 25년 네트워크 = 최강의 향간(鄉間) |

## 단계별 실행 로드맵

```
1Q: MVP 개발 + 베타 테스터 10개 업체
2Q: 정식 론칭 + 20개 고객
3Q: 월 10개 신규 고객 + AI 기능 추가
4Q: 시리즈 A 투자 유치 준비
```

## KPI 목표

| 지표 | 목표 |
|------|------|
| 1년차 월간 거래액 | 10억원 |
| 고객 확보 비용(CAC) | 100만원 이하 |
| 고객 생애 가치(LTV) | CAC의 5배 이상 |
| 클레임 처리율 | 48시간 내 100% |
