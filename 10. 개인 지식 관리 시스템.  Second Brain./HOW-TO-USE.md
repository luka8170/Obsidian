# Raw 파일 추가 가이드

> 새 원재료를 추가하고 ingest를 요청하는 방법

---

## 📂 어디에 넣는가

```
10. 개인 지식 관리 시스템.  Second Brain./raw/
├── claude-memory/   ← Claude 대화에서 추출한 지식
└── notes/           ← 그 외 모든 것
    ├── emails/      ← 업무 이메일
    ├── articles/    ← 웹 기사, 리서치
    ├── meetings/    ← 미팅 메모
    └── thoughts/    ← 즉흥적인 생각, 일기
```

---

## ✍️ Raw 파일 형식

파일명 규칙: `YYYY-MM-DD_[주제].md`

예시:
- `2026-04-19_sinokor-meeting.md`
- `2026-04-20_customs-broker-research.md`
- `2026-04-21_ai-workflow-idea.md`

파일 내용은 자유 형식 OK. 다듬지 않아도 됨.
Claude가 알아서 정제해서 wiki에 넣음.

---

## 🚀 자주 쓰는 커맨드

| 커맨드 | 설명 |
|--------|------|
| `"ingest 해줘"` | raw/ 전체 새 파일 → wiki 자동 반영 |
| `"[파일명] ingest 해줘"` | 특정 파일만 처리 |
| `"캘린더 동기화해줘"` | Google Calendar → Daily/Weekly Note 자동 업데이트 |
| `"오늘 일정 가져와줘"` | 오늘 Daily Note에 캘린더 반영 |
| `"이번 주 일정 업데이트해줘"` | Weekly Note 캘린더 섹션 갱신 |
| `"wiki에서 [주제] 찾아줘"` | 위키 기반 질의응답 |
| `"내 [주제]에 대해 정리해줘"` | 위키 종합 분석 |
| `"lint 해줘"` | 위키 전체 점검 |

---

## 📅 Daily Note 구조

매일 아침 루틴:
1. `"캘린더 동기화해줘"` → 오늘 일정 자동 반영
2. To-Do 섹션 직접 작성
3. 하루 끝에 메모/생각 기록 → `"ingest 해줘"`
