# 전략광물 투자 테마 — AI·반도체·방산 공통 수혜

## 왜 지금 전략광물인가

AI 데이터센터 → 반도체 → 방산 → 전력망 어느 산업이 성장하든 **비철금속 수요는 무조건 증가**.
쿼드(미·일·인도·호주) 등 서방 진영이 중국의 갈륨·게르마늄·안티모니 수출 통제에 대응해 공급망 재편 중.

## 핵심 광물별 수요 매핑

| 광물 | AI/데이터센터 | 반도체 | 방산 | 전력망 |
|------|-------------|--------|------|--------|
| 구리·은 | ✅ (전력선) | | | ✅ |
| 인듐·갈륨·게르마늄 | | ✅ | | |
| 안티모니 | | | ✅ (탄약·미사일) | |

## 고려아연 — 국내 유일 전략광물 원스톱 플레이어

### 경쟁력 요약
- 은·구리·인듐·안티모니 등 **20종+ 금속 동시 생산** → 어떤 테마가 뜨든 수혜
- 2026년 1Q: 매출 6조원, 영업이익 7461억원 (사상 최대 분기, **105분기 연속 흑자**)
- 매출 YoY +58.4%, 영업이익 YoY +175.2%, 영업이익률 12.3%

### 글로벌 공급망 구축 중
- **미국 테네시 '프로젝트 크루서블'**: 핵심광물 11종 + 비철금속 13종 + 반도체 황산 통합 제련소
- **호주 자회사 SMC**: 호주 자원 × 한국 제련기술 × 미국 수요 3각 구도

### 투자 관점 핵심 논리
"AI가 성장하면 은·구리, 반도체 호황엔 인듐·황산, 방산 수요엔 안티모니 — 뭐가 뜨든 고려아연은 수혜"
