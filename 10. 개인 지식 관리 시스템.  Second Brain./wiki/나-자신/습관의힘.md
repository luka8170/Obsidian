# 습관의 힘 (The Power of Habit)

> 저자: 찰스 두히그 | 핵심: 습관은 의식이 아니라 **시스템**으로 바꾼다

## 핵심 인사이트

### 1. 습관 고리 (Habit Loop)
모든 습관은 3단계 고리로 작동한다.

```
신호(Cue) → 반복행동(Routine) → 보상(Reward)
     ↑                                    |
     └────────────────────────────────────┘
```

- **신호**: 습관을 촉발하는 트리거 (시간, 장소, 감정, 사람, 직전 행동)
- **반복행동**: 실제 행동 (바꾸고 싶은 부분)
- **보상**: 뇌가 기억하게 만드는 결과

### 2. 습관 변화의 황금률
> **신호와 보상은 유지하고, 반복행동만 바꿔라**

- 나쁜 습관을 없애려 하지 말고 **다른 행동으로 대체**
- 보상을 주는 이유를 먼저 파악해야 대체 행동을 찾을 수 있음
- 예: 점심 후 간식 → 신호(점심 후), 보상(사교/기분전환) → 대체(잠깐 산책)

### 3. 핵심 습관 (Keystone Habits)
하나의 핵심 습관이 다른 습관들을 연쇄적으로 바꾼다.

- **운동**: 운동 시작 → 식습관 개선 → 수면 개선 → 집중력 향상
- **기록**: 지출 기록 → 소비 절약 → 저축 증가
- 개인과 조직 모두에 핵심 습관이 존재

### 4. 의지력은 근육이다
- 의지력은 쓸수록 소진되고, 훈련할수록 강해진다
- 피로하거나 스트레스 상황에서 의지력이 가장 낮음
- **중요한 결정/행동은 하루의 앞부분에** 배치하라
- 루틴으로 만들면 의지력 소모 없이 실행 가능

### 5. 조직의 습관 vs 개인의 습관
- 기업의 문화도 결국 집단적 습관의 총합
- 위기는 조직 습관을 바꿀 최고의 기회 (기존 루틴이 무너지는 순간)
- 좋은 리더는 팀의 핵심 습관을 설계한다

## Luka에게 적용 포인트

| 습관 고리 | 현재/개선 |
|----------|---------|
| AI 워크플로 | 신호(업무 시작) → Claude Code 실행 → 보상(시간 절약) |
| 영업 루틴 | 신호(월요일 아침) → 고객 업데이트 리포트 → 보상(관계 유지) |
| 학습 루틴 | 신호(출퇴근 이동) → 업계 뉴스/팟캐스트 → 보상(인사이트) |

## 액션 아이템
- [ ] 현재 가장 자동화하고 싶은 행동 1개 선정 → 신호/보상 분석
- [ ] 아침 루틴에 '핵심 습관' 1개 추가 (운동 or 기록)
- [ ] 중요한 영업 제안/의사결정은 오전에 처리하도록 일정 재구성
