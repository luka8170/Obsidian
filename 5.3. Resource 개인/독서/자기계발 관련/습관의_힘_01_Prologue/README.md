# 습관의 힘 - 프롤로그 (Prologue)

## 📖 내용
- **제목**: 나와 세상을 바꾸는 힘
- **페이지**: 1-20페이지
- **주요 내용**: 
  - 리자 앨런의 사례를 통한 습관의 힘 소개
  - 습관이 개인과 사회에 미치는 영향
  - 군대에서의 습관 형성 실험 사례
  - 책의 전체 구성 소개

## 🎯 핵심 메시지
습관은 개인의 삶뿐만 아니라 조직과 사회 전체를 변화시킬 수 있는 강력한 힘을 가지고 있다는 것을 보여주는 도입부입니다.
