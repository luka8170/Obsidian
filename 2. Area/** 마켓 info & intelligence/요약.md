|                                                                                                                                                                                                                                                                                                                                                                                                    | MSC VLCC 발주 관련 |
|                                                                                                                                                                                                                                                                                                                                                                                                     |                |
|                                                                                                                                                                                                                                                                                                                                                                                                     |                |
| Sinokor Ship Management CEO는 Tradewinds 뉴스 등의 전반적인 상황과 지금까지 Sinokor에서 CEO로서 업무한 경험을 비추어 볼 때, 이번에 MSC VLCC 신조 프로젝트 뉴스와 관련, 그것은 단순한 발주가 아니라, 장금상선이 초기 단계를 주도하고 MSC가 결합하는 형태가 될 것이 높을 것으로 예측했습니다.                                                                                                                                                                                                      |                |
| 즉, 선(先) 장금상선 주도, 후(後) MSC 결합으로, Sinokor Ship Management CEO는 신조(New building)가 진행될 경우, **"저기(장금상선)서 시작하고 MSC가 날아오는 형태가 되지 않을까 싶다"**고 언급했습니다,. 이는 장금상선이 계약 및 건조의 초기 구조를 수립하고, 이후 MSC가 자본을 대거나 최종 인수하는 방식으로 결합하는 구조를 시사합니다.                                                                                                                                                                           |                |
| 또한, BBCHP 방식으로 선박이 건조 될 가능성이 높다고 예측하였으며,  Sinokor Ship Management CEO는 구조적 이유로 인해 BBCHP(Bareboat Charter with Hire Purchase) 방식이 적용되었을 가능성을 제기했습니다, MSC는 자금력은 있으나 아시아 지역의 VLCC 운영 네트워크가 필요하고, 장금상선은 이를 제공할 수 있어 상호 간의 이해관계가 맞는 구조입니다,                                                                                                                                                               |                |
| (뉴스에서도 장금상선은 VLCC 관련 Worldwide network을 MSC network을 이용할 수도 있다고 언급 되는 등, Sinokor와 MSC의 VLCC와 Containership관련 폭넓은 Partnership이 체결 된 것으로 보입니다.)                                                                                                                                                                                                                                                       |                |
|                                                                                                                                                                                                                                                                                                                                                                                                     |                |
| 일례로, 선박 건조 시, Sinokor는 건조 감독 및 품질 관리 장악하고 있는 것을 뒷받침한다고 하겠습니다.                                                                                                                                                                                                                                                                                                                                       |                |
| 신조 선박의 건조 관리는 장금상선이 주도하며, 특히 조선소에 대한 강력한 통제권을 행사하고 있습니다.                                                                                                                                                                                                                                                                                                                                            |                |
| 장금상선은 신조 감독(Superintendent)으로 해당 조선소 퇴임 임원들을 영입하여 배치하며, 이들 출신 감독관들은 조선소 내부 사정과 하청 업체 구조를 훤히 꿰뚫고 있어, 시운전(Sea trial)이나 건조 과정에서 문제가 발생할 경우 조선소 관리자를 거치지 않고 현장 반장을 직접 호출해 즉각 시정 조치를 내릴 정도로 강력한 영향력을 행사하고 있습니다,                                                                                                                                                                                          |                |
| (또한, VLCC에 대한 풍부한 신조 및 운항선 관리 경험이 있는 장금상선이 MSC의 신조 발주에 대한 건조 계약 및 기술적 리드를 할 가능성은 높아 보입니다.)                                                                                                                                                                                                                                                                                                          |                |
|                                                                                                                                                                                                                                                                                                                                                                                                     |                |
| 요약하자면, MSC가 VLCC를 중국조선소에서 건조할 때, 선박 건조에 대한 계약 및 건조 관련 초기 구조는 Sinokor가 리드하고, MSC는 자본을 대고, 최종적으로 인수하는 방식의 결합구조가 예상 될 가능성이 현재로서는 높게 예측 되고 있습니다.                                                                                                                                                                                                                                                        |                |
