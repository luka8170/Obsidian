# 대치동 초등 사교육 로드맵 — 국·영·수 분석

## 핵심 인사이트

- **사교육 시작 연령**: 영어 5세, 수학 6세(사고력), 국어(독서·논술) 7세. 초등 4학년부터 본격 대입 레이스 시작
- **과목별 전환점 — 초4**: 영어는 미국식(듣·말·읽·쓰기) → 한국식(문법·독해 내신·수능) 전환, 수학은 사고력 → 교과 심화, 국어는 독서 → 논술·비문학 집중으로 학원 지형이 달라짐
- **수학이 변별력 핵심**: 수능 영어 절대평가(90점↑ 전원 1등급) 이후 수학이 최상위권 변별 주요 과목. 이과 쏠림으로 문과 지원 교차합격('문과침공') 심화 → 수학 선행·심화가 전략적 우선순위
- **선행의 구조**: 대치동 상위권은 제 학년 대비 3~5년 선행. 반복을 위해 선행하고, 선행하니 반복이 가능한 순환 구 
- 후 까. 조. 뒤늦게 시작하면 진도 격차 따라잡기 어려움
- **국어 변별력 급부상**: 2022년 기준 최근 3년 사교육비 증가율 1위가 국어(26.8%). 수능 비문학이 최상위권 변별 지점. 독해력은 유아기부터 장기 축적 필요 — 단기 속성 불가
- **영어 학습 본질**: PEAI 김용 부원장 — "영어는 학습이 아니라 습득. 쉽고, 재밌고, 꾸준하게." 레벨 경쟁보다 아이 수준에 맞는 학원 + 자신감(Confidence) 유지가 핵심
- **수학 심화 철학** (황소 이정현 대표): 잘 가르치는 것보다 스스로 풀어보는 경험이 중요. 개념·수학적 경험·사고력 세 가지가 수학 실력의 근육. 어려운 문제를 끝까지 붙잡고 푸는 경험이 고차원적 수학 경험

## 내 사업 적용 액션 (아들 교육 로드맵)

- [ ] 현재 학년 기준 과목별 위치 파악: 영어(미국식/한국식 전환 시점?), 수학(사고력→교과 전환 시점?), 국어(독서량·비문학 노출 수준?)
- [ ] 초4 전환점 대비 계획 수립: 영어는 초3까지 미국식 완성 목표 설정, 수학은 사고력 기반 위에 교과 심화 시점 결정
- [ ] 국어 독해력 조기 구축: 매일 독서 습관화 (2주 1권 최소 기준), 비문학 지문 노출 시작 시점 결정
- [ ] 수학 선행 속도 점검: 선행보다 현행 개념 완전 소화가 우선 — 황소 원칙("진도보다 깊이") 적용
- [ ] 영어 학원 선택 기준 재설정: 레벨 테스트 합격보다 아이가 재밌게 다니는지, 리더 역할 할 수 있는 수준인지 확인
