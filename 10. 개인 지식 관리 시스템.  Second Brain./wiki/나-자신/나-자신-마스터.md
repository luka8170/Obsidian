## 4. 사고방식 & 마인드셋

### 4-1. 더 시스템 — 스콧 애덤스
> **패배자는 목표를 설계하고, 승자는 시스템을 만든다.**

**목표 vs 시스템**
| 목표(Goal) | 시스템(System) |
|------------|--------------|
| 달성 전까지 항상 실패 상태 | 실행할 때마다 성공 경험 |
| 특정 시점의 결과물 | 매일 반복하는 행동 패턴 |
| 관세사 합격 | 매일 2시간 공부하기 |

**핵심 인사이트**
- 열정은 성공의 원인이 아니라 결과 — 잘할 때 열정이 생긴다
- 기술 조합으로 성공 확률 올리기: 해운 도메인 × AI 활용 × 관세 지식 × 영업력 = 희소성
- 개인 에너지 관리가 모든 수행의 기반 (건강·식습관·수면이 전부)
- 올바른 이기심: 자신을 먼저 챙겨야 남도 도울 수 있다

**Luka 적용**: "관세사 합격"(목표) → "매일 1시간 수험 공부"(시스템). [[커리어-전환-마스터]] 참조.

### 4-2. 생각하라 그리고 부자가 되어라 — 나폴레온 힐
> **생각 → 믿음 → 열망 → 잠재의식 → 물리적 현실**

**13가지 성공 원칙 핵심 요약**
1. **열망**: 소망이 아닌 불타는 열망. 퇴로를 태워라. 6단계: 목표 금액 → 대가 → 날짜 → 계획+즉시행동 → 글로 써라 → 하루 2회 소리 내어 읽기
2. **믿음**: 잠재의식은 반복하는 생각을 현실로 받아들인다. 감사 선언문 매일 읽기
3. **자기암시**: 감정이 담기지 않은 말은 잠재의식에 닿지 않는다. 이미 이룬 것처럼 보고 느끼기
4. **전문 지식**: 아이디어에 전문 지식을 조합하는 능력이 진짜 자산
5. **결단력**: 빠르게 결정하고 천천히 바꿔라. 미루는 습관이 실패의 공통 요인
6. **끈기**: 믿음 + 명확한 목적 + 자기 인식 + 계획

**두려움의 6가지 유령** (모두 마음에서 비롯된 것):
가난 / 비난 / 건강 악화 / 사랑 상실 / 노화 / 죽음

**Luka 적용**: 커리어 전환 열망을 선언문으로 → 아침·저녁 소리 내어 읽기. 첫 계획 실패해도 포기 X.

### 4-3. 습관의 힘 — 찰스 두히그
> **습관은 의식이 아니라 시스템으로 바꾼다**

**습관 고리**: 신호(Cue) → 반복행동(Routine) → 보상(Reward)

**황금률**: 신호와 보상은 유지하고, 반복행동만 바꿔라

**핵심 습관(Keystone Habits)**: 하나가 연쇄를 만든다
- 운동 시작 → 식습관 개선 → 수면 개선 → 집중력 향상

**의지력은 근육이다**: 쓸수록 소진, 훈련할수록 강해짐 → 중요한 결정/행동은 하루 앞부분에 배치

### 4-4. 완전한 몰입(LIT) — 제프 카프 & 몰입 — 황동문

**LIT (제프 카프)**
- 뇌가 에너지를 최적으로 활용하는 고도 몰입 상태
- 집중력은 기를 수 있는 근육 — 훈련 가능
- 핵심 도구 10가지: 호기심 연료 / 환경 설계(알림 OFF) / 움직임 / 수면 / 작은 성공 쌓기 / 의미 연결 / 협업 / 정기 휴식 / 두려움 직면 / 감사

**몰입 (황동문)**
- 몰입의 3가지 신호: 자신감 급상승 / 호기심 극대화 / 사고하는 즐거움
- "Work Hard에서 Think Hard로" — 노동량이 아닌 사고의 질 전환

**공통 인사이트**: 몰입은 의도적으로 훈련 가능한 기술. 수면과 운동 없이는 몰입 불가능.

### 4-5. 불확실성의 기회 — Nathan Furr
> **불확실성은 위협이 아닌 기회의 조건**

**4단계 프레임**: Reframe(재정의) → Prime(준비) → Do(작은 실험) → Sustain(지속)

**핵심**: 손실 회피 편향이 불확실성을 과대평가하게 만든다. "실패하면 어쩌나" → "성공하면 무엇이 가능한가"로 전환.

불확실성에는 두 종류: 위험(Risk, 확률 계산 가능) vs. 불확실성(Uncertainty, 실험으로 탐색).

**Luka 적용**: 커리어 전환 고민 시 "최소 실험"으로 접근. 불확실성을 느낄 때 → "이 상황에서 새롭게 가능해진 것은 무엇인가?"

### 4-6. 회복탄력성 — 김주환
> **시련을 행운으로 바꾸는 마음 근력**

성공한 사람들의 공통점은 실패 횟수가 적은 것이 아니라 **회복 속도가 빠른 것**.

**3대 구성 요소**
- 자기 조절 능력 (감정 조절, 충동 통제, 원인 분석)
- 대인 관계 능력 (소통, 공감, 자아 확장력)
- 긍정성 (낙관성, 감사, 생활 만족도)

**회복탄력성이 높은 사람**: 실패를 일시적·특수한 사건으로 본다 ("이번엔 이랬지만 다음엔 달라").

**키우기**: 감사 일기(매일 3가지) / 강점 발견 / 의미 부여 / 관계 투자

- 혈당·혈압·체중 중 하나라도 이상 → 암·심혈관 리스크 급증

### 뇌 건강 & 항노화
- **미세플라스틱**: 간·콩팥보다 뇌에 더 많이 축적 → 치매·뇌졸중 위험 → 플라스틱 용기 가열 금지

### 영양제 오해와 진실 (정재훈 약사)
- **"건강한 아이는 비타민D 하나면 된다"** — 불안 마케팅이 시장을 키운 것

- 성장주사: 의학적 원인 없으면 연 1000만원에 1~2cm → 효과 미미
- **진짜 성장 치트키**: 수면(성장호르몬 분비 폭발) + 고강도 운동(10~20배 분비) + 균형 식단

## 6. 자녀 교육 인사이트

### 수학은 암기다 — 김현정
> 수학 실력은 **개념 기반 암기 시스템**으로 만든다

**수학에서 외워야 할 4가지**: 정의 / 용어 / 공식(증명 후 암기) / 모개념

**백지테스트**: 공부 전 백지에 해당 단원의 개념·공식을 스스로 써본다. 못 쓰는 것 = 아직 내 것이 아님.

핵심 원칙: 개념서 한 권을 완벽하게. 오답노트보다 오답 체크(○△× 표시 + 반복).

**학습 순서**: 개념 읽기 → 백지테스트 → 모개념 적고 문제풀기 → 오답 원인 분류(실수/시간/개념) → 반복

### 학군지 변화 & 2026 교육 트렌드

**학군지 구조 변화**
- 기존 학군지(분당·일산·노원) 학생 수 감소, 신도시 증가
- 학군지 기준이 "지역" → "개별 학교 경쟁력"으로 이동
- 고교학점제(2025~): 학생 수 많은 학교(300명+)가 과목 다양성·등급 안정성 유리

**의대 → 영과고 트렌드 (2026)**
- AI 반도체 엔지니어 몸값 급등 (엔비디아 신입 2억, 딥시크 3억+) → 영재학교 인기 회복
- 2027 영재학교 평균 경쟁률 6.21:1 (역대 최고)
- 최상위권 로드맵: **초등 4학년 2학기 중등 수학 선행 시작** → KMO 준비

**사립초→국제중 로드맵**
- 인기 루트: 영유 → 사립초 → 국제중 → 특목·자사고
- 2026 국제중 평균 경쟁률 17.43:1 (역대 최고, 대원 23.55:1)
- 이동 적기: 3~4학년 (이후엔 교과 격차 심화)

**스마트폰 & 교육 (강남 중동고 사례)**
- 강남 최초 스마트폰 수거 → 학교폭력·청소년 도박의 시작점 차단
- "학생 인권만큼 교권도 중요. 학교는 학원 아님" — 이명학 교장

**영재고 vs. 일반고 선택 기준**
- 수학·과학 수업 중간 반 수준이면 일반고가 현실적
- 경쟁심 약한 기질 → 일반고 내신 집중이 더 유리

**학원가 대이동 (2026-07-07 업데이트)**
