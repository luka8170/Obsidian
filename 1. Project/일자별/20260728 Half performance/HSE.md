


**사용 시스템**: 모바일 앱 "MAIA" (2026년 9월 중순경 신규 앱으로 교체 예정이라는 안내가 있었습니다.)

**Safety Walk 입력 방법**

1. 앱 좌측 상단의 삼선(☰) 메뉴 아이콘 클릭 → 만약 이 아이콘이 보이지 않으면 SW(Safety Walk) 권한이 없는 것이므로 관리자(Yo-Sep KIM)에게 권한 요청 필요
2. "New Inspection" 선택
3. Space(예: M&O), Form(예: "Safety Walk - Office"), Checklist language, Inspection Date(날짜/시간) 입력 후 "CONFIRM" 클릭
4. 또는 "Planning" 메뉴의 Planning Week(주간 캘린더) 화면에서 해당 점검일을 찾아 들어가서 입력 가능
5. 입력 완료 후 반드시 우측 상단의 **Sync 버튼**을 눌러야 NEXUS 시스템으로 데이터가 전송됩니다.

**2MFMS 관련**

- 2MFMS는 **당일 입력만 가능**하며 소급 입력이 불가합니다.
- 반면 Safety Walk나 Unsafe Condition은 소급 입력이 가능합니다.

**결과 확인**

- 입력한 내용/카운팅 결과는 NEXUS([https://nexus.bureauveritas.com)에서](https://nexus.bureauveritas.com\)%EC%97%90%EC%84%9C) 확인 가능하며, 사내 OneLogin 포털 → QHSE & TQR → Nexus 경로로 접속합니다.
