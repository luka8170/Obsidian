## 5. Google Drive 연결

**사용자:** 구글드라이브에 내 맥 pc와 연결 가능하나

**Claude:** Mac에 직접 연결되는 것은 아님. Google Drive 커넥터로 Drive에 파일을 올리고, Mac의 'Google Drive for Desktop'이 동기화하는 방식. Mac의 파일을 직접 읽거나 쓸 수는 없음.

**사용자:** 어 진행해 → `main_master_updated.xlsx`(약 190KB) 업로드 시도.
- 커넥터가 파일 경로 없이 base64 문자열만 받아 한 글자 오류에도 xlsx가 깨질 위험이 있어 업로드하지 않음.
- 대안 3가지 제시(직접 업로드 / 추가분만 구글 시트 / 구글 시트로 전체 변환).

**사용자:** 지금 맥 pc 를 안가지고 있어서 그래 → 추가분만 구글 시트로 올리는 방법을 추천.

**사용자:** 2번으로 올려줘 → 내 드라이브 최상단에 구글 시트 `2026 비용 추가분 (9/18~10/16)` 생성.
- 링크: https://docs.google.com/spreadsheets/d/13S7YG3FT1-aZUplqJCjpWNhyMZukLGLzRYZhRdK9DDs/edit
- 구글 시트가 승인번호 앞의 0을 지울 수 있음(원본 xlsx에는 그대로 있음).

- 기능: 왼쪽 폴더 트리, 제목/본문 검색, 뒤로/앞으로, 오른쪽 목차, `[[위키링크]]`, frontmatter 속성, 콜아웃, 체크리스트, 표, `==하이라이트==`, `#태그`.

- 볼트 전체는 노트 1,945개·약 78MB라 페이지에 통째로 넣을 수 없어 실시간 읽기 방식을 선택.

**문제 해결 과정**
1. "링크 열어봤는데 안 나와" → 가짜 Drive 응답으로 직접 테스트(트리·본문·콜아웃 정상). 연결 상태 표시와 안내 문구 추가.
2. "PARA 업무와 PARA 개인이 안보이잖아" → 연결 전에는 트리가 통째로 비던 문제 수정(세 폴더를 먼저 표시).
3. 보내준 iPad 화면: Drive 연결은 정상(마지막 연 노트·최근 수정 노트 표시). 패널이 좁아 폴더 목록이 ☰ 뒤에 숨는 레이아웃이었음 → 홈 화면에 `폴더` 섹션 추가.
