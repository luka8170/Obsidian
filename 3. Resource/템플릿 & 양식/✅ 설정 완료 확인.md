## 🚀 바로 사용 시작하기

### Obsidian 재시작 필요!
설정 파일이 변경되었으므로 **Obsidian을 완전히 종료하고 다시 실행**해야 합니다.

**Mac에서 Obsidian 완전 종료:**
1. `Cmd + Q` (또는 Obsidian → Quit Obsidian)
2. 다시 Obsidian 실행

### 테스트 방법

#### 1️⃣ Calendar에서 일일 노트 생성
- 오른쪽 Calendar에서 오늘 날짜 클릭
- Daily Template이 자동 적용되는지 확인
- 파일 위치: `1. Project/2026-01-05.md`

#### 2️⃣ 주간 노트 생성
- `Ctrl/Cmd + P` → "Open Weekly Note" 검색
- Weekly Template이 자동 적용되는지 확인
- 파일 위치: `1. Project/Weekly/2026-W01.md`

#### 3️⃣ 월간 노트 생성
- `Ctrl/Cmd + P` → "Open Monthly Note" 검색
- Monthly Template이 자동 적용되는지 확인
- 파일 위치: `1. Project/Monthly/2026-01.md`

## 🔧 문제 해결

### 템플릿이 적용 안 될 경우
1. Obsidian 완전 재시작 (Cmd + Q → 재실행)
2. Settings → Community plugins에서 Periodic Notes, Templater 활성화 확인
3. 템플릿 파일 경로 확인

### Calendar가 안 보일 경우
- 오른쪽 상단 사이드바 토글 (세로 선 3개) 클릭
