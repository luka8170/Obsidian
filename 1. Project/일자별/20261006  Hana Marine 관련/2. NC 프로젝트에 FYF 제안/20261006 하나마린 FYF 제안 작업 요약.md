# 하나마린 FYF 6,500불 제안 — 작업 요약

## 배경

- 하나마린 대표(박주현)가 2026-10-06 직접 전화해 BV 검사비(경쟁사 KR 대비 2~3배)와 임시(수중) 검사 시 BV 인증 다이버 비용(500만원 vs 일반 120만원)에 대한 불만을 제기함. ([[박주현 대표 통화 내용]])
- 동시에 하나마린은 일본 조선소 한 곳에 신조선 발주를 집중할 계획이며, 기존 선단 FYF 협상 타결이 BV의 신조선 선급 확보 기회와 직결됨을 확인 (BV Japan Kano-san 메신저 기록, `3. 일본 조선소 상황 확인` 폴더). 이번 주 Shin Kurushima 조선소가 BV Kobe를 방문해 4,400DWT 케미컬탱커 건을 긍정적으로 논의했으나, 같은 자리에서도 하나마린은 BV FYF 수준이 너무 높다는 입장을 재확인.
- `1. 하나마린 FYF 체결/NS team 제안 FYF_ Profit simulation_HANA MARINE (1).xlsx` 파일에서 하나마린 측이 제안가를 **7,000불 → 6,500불**로 직접 수정함을 확인.

## 진행한 작업

1. NS team 시뮬레이션 파일(6,500불 반영본)을 읽어 선박별/선단 전체 수익성(5년 누적) 재계산 — 원본 파일의 "합계" 행이 8척 중 5척만 합산하는 오류를 발견해 8척 전체 기준으로 직접 재계산.
2. Christophe Vaes 앞 승인 요청 보고서를 **국문/영문 .md, 영문 .eml(무채색 HTML)** 3종으로 작성 — 요청사항 / 배경 / 재무 근거(선박별 테이블) / 참고할 점 / 다음 단계 구조로 통일.
3. 내용을 여러 차례 다듬음: 쉬운 영어 → 더 간결한 영어 → 핵심 위주 국문 보고서 → "7,000에서 낮췄다"는 비교 표현 전부 제거(6,500을 최초 제안값으로만 서술) → 영문 버전을 국문 최종본 기준으로 재작성 → eml도 동일 기준으로 맞춤.
4. `1. Project/일자별/20261006. Key Client Analysis/하나마린 정기임시검사 수익성분석.xlsx`의 `05_시나리오` 탭도 6,500 단일 제안 기준으로 정리(참고용 7,000 비교 컬럼 삭제), LibreOffice로 재계산 검증 후 저장.
