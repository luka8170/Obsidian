# 수학은 암기다

> 저자: 김현정 | 핵심: 수학 실력은 **개념 기반 암기 시스템**으로 만든다

## 핵심 인사이트

### 1. 수학에서 외워야 할 4가지
- **정의** — 무조건 외운다 (약속이자 기반)
- **용어** — 정확한 뜻을 외운다 (독해력이 풀이력)
- **공식** — 증명한 다음 외운다 (이해 없는 암기는 오남용)
- **모개념** — 문제풀이에 쓰이는 가장 간단한 개념을 문제 유형과 함께 외운다

### 2. 공식은 증명 후 암기
> 증명 못하는 공식은 어떤 문제에 써야 할지 확신이 없어 실수로 이어진다

- 증명 → 이해 → 남에게 설명 가능한 수준 → 그 후 암기
- 개념서 목차도 외운다 (단원 전체 구조가 머릿속에 있어야 연결됨)

### 3. 백지테스트 (문제풀이 준비단계)
- 공부 전 백지에 해당 단원의 개념·공식을 스스로 써본다
- 못 쓰는 것 = 아직 내 것이 아닌 것 → 다시 개념서로 돌아간다
- 시험 전 가장 효과적인 최종 점검 방법

### 4. 비장의 노트 풀이법
- 풀이할 노트 + 개념서 + 시험지를 항상 함께 들고 다닌다
- 노트에 풀이 과정을 단계별로 적는다 (머릿속으로만 풀지 않는다)
- 틀린 문제는 3가지로 분류: ① 단순 실수 ② 시간 부족 ③ 개념 모름

### 5. 오답 노트보다 오답 체크
- 오답 노트 만들기에 시간 낭비하지 말 것
- 문제집/시험지에 직접 ○△× 표시 후 반복
- 틀린 이유(개념 부족인지 실수인지)를 파악하는 것이 핵심

### 6. 개념서는 한 권으로
- 여러 권 사서 얕게 보는 것보다 **한 권을 완벽하게** 반복
- 문제집도 마찬가지: 한 권을 완벽히 끝내는 것이 목표

## 학습에 적용하는 법

| 단계 | 방법 |
|------|------|
| 개념 입력 | 교과서/개념서 읽기 (풀기 X, 읽으며 외운다는 기분으로) |
| 확인 | 백지테스트 — 아무것도 보지 않고 개념·공식 써보기 |
| 문제 적용 | 모개념을 문제 위에 적고 풀기 |
| 오답 처리 | 해설지 보고 풀이의 행간 개념 파악, 시험지에 직접 표시 |
| 반복 | 같은 책을 여러 번, 표시된 문제 위주로 |

## 액션 아이템
- [ ] 공부할 단원의 개념·공식을 백지에 써보는 습관 만들기
- [ ] 풀이 노트 + 개념서 + 문제집 세트로 들고 다니기
- [ ] 틀린 문제는 원인 분류(실수/시간/개념) 후 표시
- [ ] 개념서 목차를 외울 때까지 반복 읽기
