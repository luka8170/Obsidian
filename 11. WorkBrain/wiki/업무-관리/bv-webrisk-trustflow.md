# BV WebRisk → TrustFlow 전환 & 승인 강화 정책

## 핵심 인사이트

- **모든 WebRisk 요청 사전 승인 의무화**: CSR, 위원회, 선물 등 전부 M&O President(Alex Gregg-Smith) 사전 결재 필수 — 미승인 시 자동 반려
- **스폰서십/기부 연간 3~4건 한도**: 각 지역 SVP 재량으로 예외 승인 가능하나, 신청 시 "승인된 예외 항목임"을 명기해야 함
- **TrustFlow 마이그레이션**: 2026년 7월 중순 기존 WebRisk 시스템 → TrustFlow 전환 (기능 큰 변화 없음)
- **조기 신청 강조**: 행사 임박 신청은 승인 불가 수준. 본사 검토 기준 강화됨

## 내 사업 적용 액션

- [ ] 2026년 하반기 고객사 행사/세미나 후원 계획 있으면 **7월 이전에 SVP Jeffrey Guo 통해 사전 승인 요청**
- [ ] TrustFlow 전환 후 기존 WebRisk 계정/접근 방법 변경 여부 확인 (7월 중순 이후)
- [ ] 연간 스폰서십 예산 집행 시 "예외 항목 코드" 기재 방법 확인

## 원문 발췌

> "사전 승인이 없는 요청은 반려(Reject)됩니다."
> "각 지역 SVP는 연간 3~4건의 예외적인 스폰서십 및 기부만 제안할 수 있습니다."
