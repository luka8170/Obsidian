# 슈퍼리치 영업시스템

> 저자: 심길후 | 핵심: 고객이 먼저 찾아오는 자동 영업 시스템 구축

## 핵심 인사이트

### 1. 신기루의 법칙 — 방향이 먼저다
열심히 하는 것보다 **올바른 방향**이 중요하다. 사막에서 탈출하려면 희망만이 아니라 정확한 방향이 필요하듯, 영업도 방향 없는 열정은 소모전이다.

- 남들이 다 파는 상품으로는 가격 경쟁에서 벗어날 수 없다
- 내가 더 잘할 수 있는 **나만의 아이템**(전문성 기반)을 찾아야 함
- 현재 일을 버리는 게 아니라, 방향을 살짝 바꾸는 것

### 2. 로볼(Low Ball) 전략 — 먼저 주어라
가치를 먼저 무료로 제공해서 고객의 신뢰를 쌓는다. 신뢰가 쌓이면 고객은 자연스럽게 유료로 전환된다.

- 정보, 인사이트, 샘플 등을 선제 제공
- 고객이 "이 사람은 나를 도우려 한다"고 느끼게 만들기
- 결과: 거절률 급감, 관계 깊이 증가

### 3. 멘토 포지셔닝 — 판매자가 아닌 전문가로
상품을 파는 사람이 아니라 **가르쳐주는 전문가**로 포지셔닝하면 고객이 먼저 찾아온다.

- 블로그, 콘텐츠, 강의 등으로 전문성 공개
- 상담비를 받는 구조가 오히려 신뢰를 높임
- "왜 이 사람에게 사야 하는가"에 대한 답이 명확해짐

### 4. 개입상품 — 고객을 락인하는 구조
핵심 상품 전에 **진입 장벽이 낮은 상품**으로 먼저 관계를 맺는다.

- 로볼(무료 또는 저가) → 개입상품(중간가) → 핵심상품(고가)
- 속박전제: 개입상품이 핵심상품 구매를 자연스럽게 유도

### 5. 셀프 어프로칭 — 고객이 알아서 오는 시스템
영업하러 나가는 것이 아니라, **시스템이 고객을 데려오는** 구조 만들기.

- DB 확보 → 레터/문자 발송 → 상담 예약 → 클로징
- 자동화된 파이프라인: 한 번 만들면 반복 작동

## BV 영업에 직접 적용 포인트

| 개념 | BV 영업 적용 |
|------|-------------|
| 로볼 | 선급 인사이트 리포트, 시장 동향 자료를 고객에게 먼저 공유 |
| 멘토 포지셔닝 | Sinokor/HMM 같은 주요 고객사에 전문가 컨설턴트로 포지셔닝 |
| 개입상품 | CAC/TOC 이전 소규모 서비스 → FYF 대형 계약으로 확장 |
| 셀프 어프로칭 | BV 뉴스레터, 기술 세미나로 잠재고객 DB 자동 유입 |
