# 부모님께 증여하는 방안 (최종 해결책)

## 실제 상황
- 배우자 명의: 20억 (양도세 부담 큼)
- 본인 명의: 2억 (양도세 부담 작음)
- **문제: 2억 주택이 아무리 싸게 내놓아도 안 팔림**

## 부모님께 양도하는 방안

### 방법 1: 부모님께 증여 ✅ (추천)

**장점:**
- ✅ 1가구 2주택 → 1가구 1주택 전환 (즉시 효과)
- ✅ 20억 주택을 1주택 비과세로 매각 가능
- ✅ 부모님이 무주택자면 취득세 감면 가능
- ✅ 시장에서 안 팔리는 문제 해결

**증여세 부담:**
```
부모-자녀 간 증여공제: 10년간 5천만원

[2억 주택 증여 시]
- 과세표준: 2억 - 5천만원 = 1.5억
- 증여세: 약 1,500만원 (10%~20% 구간)
- 취득세: 약 700만원 (3.5%)
- 총 비용: 약 2,200만원
```

**vs 2주택 상태로 20억 매각 시 양도세: 수억원**
→ **훨씬 유리!**

### 방법 2: 부모님께 저가 매매

**구조:**
- 아들 → 부모님께 2억에 매매
- 시세대로 거래 (증여세 회피 아님)
- 부모님이 실제 구매자금 있어야 함

**장점:**
- ✅ 증여세 없음
- ✅ 1가구 1주택 전환
- ✅ 부모님 주거 해결 + 세금 절감 일석이조

**단점:**
- 부모님께 2억 구매자금 필요
- 본인 양도세 발생 (하지만 2주택 중과보단 낮음)

### 방법 3: 부모님께 증여 후 바로 매각 (신중 필요)

⚠️ **증여 후 즉시 매각하면:**
- 세무서에서 "증여세 회피 목적" 의심 가능
- 부당행위계산부인 적용 위험
- 하지만 실제로 안 팔려서 그런 것이므로 소명 가능

**안전한 방법:**
- 증여 후 최소 6개월~1년 경과 후 매각
- 또는 부모님이 실제 거주 후 매각

## 세금 비교 시뮬레이션

### [A안] 2주택 상태로 20억 매각
```
20억 주택 양도세 (2주택 중과세)
- 취득가 10억이라 가정
- 양도차익: 10억
- 양도세율: 최대 75% (기본세율+중과+지방세)
- 예상 양도세: 5~7억원
```

### [B안] 부모님께 2억 증여 → 20억 1주택 매각
```
1단계: 2억 증여
- 증여세: 1,500만원
- 취득세: 700만원
- 소계: 2,200만원

2단계: 20억 1주택 매각
- 보유 2년+거주요건 충족 시
- 12억까지 비과세
- 12억 초과 8억분만 과세
- 예상 양도세: 1~2억원

총 부담: 약 1.2~2.2억원
```

**절감액: 3~5억원!**

## 실행 시 체크포인트

### 1. 부모님 상황 확인
- ✅ 무주택자 여부 (취득세 감면)
- ✅ 연령 (만 60세 이상이면 일부 세제혜택)
- ✅ 향후 상속 계획과의 정합성

### 2. 증여 vs 매매 선택
```
[부모님 자금 있음] → 매매 (증여세 없음)
[부모님 자금 없음] → 증여 (증여세 2,200만원)
```

### 3. 20억 주택 비과세 요건 재확인
- 보유기간 2년 이상
- 조정대상지역이면 거주 2년 이상
- 1가구 1주택 상태 유지

### 4. 타이밍 전략

**급한 경우:**
```
1월: 부모님께 증여/매매
2월: 1가구 1주택 상태 확정
3월~: 20억 주택 매각 진행
```

**여유 있는 경우:**
```
증여 후 6개월~1년 경과
→ 부모님이 실거주 또는 매각 준비
→ 20억 주택은 1주택 비과세로 매각
```

## 추가 고려사항

### 1. 부모님 입장에서
**장점:**
- 자녀 세금 절감 도움
- 무주택자 → 유주택자 (주거 안정)
- 향후 상속재산 증가

**리스크:**
- 증여세 납부 부담 (자녀가 대신 납부 가능)
- 보유 중 재산세 부담
- 향후 상속 시 상속세 과세가액 증가

### 2. 형제자매가 있다면
- 나중에 상속 시 특별수익으로 계산될 수 있음
- 사전 가족 합의 필요

### 3. 법적 안정성
- ✅ 완전히 합법적인 방법
- ✅ 실제 증여/매매이므로 가장이혼과 달리 안전
- ✅ 세무조사 받아도 정당한 거래로 인정

## 최종 권고안

### 추천 시나리오
```
1단계: 부모님께 2억 주택 증여
- 비용: 약 2,200만원 (증여세+취득세)

2단계: 1가구 1주택 상태 확정
- 증여 완료 후 즉시 효과 발생

3단계: 20억 주택 매각
- 1주택 비과세 요건 확인 후 매각
- 12억 초과분만 과세

절감액: 3~5억원
가정 안정: 유지
합법성: 완벽
```

### 실행 전 필수 상담
1. **세무사**: 정확한 세금 계산 및 신고 대행
2. **가족회의**: 부모님, 배우자 동의
3. **법무사**: 증여 또는 매매 계약서 작성

## 결론

**부모님께 증여/매매하는 방법은:**
- ✅ 2억 주택 안 팔리는 문제 해결
- ✅ 1가구 1주택 전환으로 20억 주택 절세
- ✅ 가장이혼보다 훨씬 안전하고 합법적
- ✅ 3~5억원 이상 절감 가능

**2,200만원 투자로 3~5억원 절감**한다면 매우 현명한 선택
