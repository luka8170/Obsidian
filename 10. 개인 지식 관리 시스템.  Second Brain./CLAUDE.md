# CLAUDE.md — Second Brain 시스템 설계도

## 목적
이 vault는 Luka(한상진)의 **개인 지식**을 관리한다 — 독서, 자기계발, 커리어 전환, AI 생산성.
업무(해운 영업, BV Korea) 관련 내용은 **11. WorkBrain** vault에서 별도 관리.
새로운 AI 대화에서 개인적 컨텍스트가 필요할 때 이 위키를 참조한다.

## Raw 라우팅 판단 트리

새 파일이 들어오면 ingest 전에 **어느 vault 소속인지 먼저 판단**한다.

| 내용 유형 | 소속 vault | 예시 |
|-----------|-----------|------|
| 독서, 자기계발, 마인드셋 | ✅ Second Brain | 습관, 몰입, 인간관계 |
| AI 도구 학습, 워크플로 실험 | ✅ Second Brain | Claude 활용법, Obsidian 설정 |
| 커리어 전환, 투자, 창업 준비 | ✅ Second Brain | 관세사, 포워더 창업, ETF |
| 아들 교육, 가족 건강 | ✅ Second Brain | 수학 학습법, 영양 정보 |
| 해운 업계 동향, 고객사 분석 | ❌ WorkBrain | Sinokor, VLCC, 선박금융 |
| BV Korea 업무, 영업 전략 | ❌ WorkBrain | 미팅 기록, 고객 관계 |
| 해운 영업에 AI 도구 적용 | **브리지** → 둘 다 | AI로 고객 리서치 자동화 |

**브리지 인사이트 처리**: 두 vault에 모두 해당하는 내용은 각 vault에 요약하고 상호 참조 메모를 남긴다.
- Second Brain 쪽: `> 🔗 WorkBrain 연결: [[페이지명]] 참조`
- WorkBrain 쪽: `> 🔗 Second Brain 연결: [[페이지명]] 참조`

**판단이 모호할 때**: "이 인사이트가 BV 업무 외에서도 쓰이는가?" → Yes면 Second Brain, No면 WorkBrain.

## 핵심 규칙
- **raw/** 폴더는 불변. Claude는 읽기만 하고 절대 수정하지 않는다.
- **wiki/** 폴더는 Claude가 전적으로 소유. 사람은 읽기만 한다.
- 모든 위키 페이지는 관련 페이지를 `[[위키링크]]`로 상호 연결한다.
- `_Index.md`는 새 페이지가 생길 때마다 항상 업데이트한다.

## 마스터 파일 원칙 ⭐
각 wiki/ 하위 디렉토리에는 **반드시 마스터 파일 1개**가 존재해야 한다.

- **마스터 파일은 같은 디렉토리의 모든 하위 파일 내용을 종합**하는 단일 진실 원천(Single Source of Truth)이다.
- 새 파일이 디렉토리에 추가되거나 기존 파일이 업데이트되면, **마스터 파일도 반드시 함께 업데이트**한다.
- lint 실행 시 마스터 파일의 종합성을 검증하고 누락 내용을 보완한다.
- 마스터 파일 파일명: `{디렉토리명}-마스터.md` 또는 `{디렉토리명}-마스터플랜.md`

## 3가지 핵심 작업

### 1. INGEST (원재료 소화)
raw/ 폴더에 새 파일이 추가되면:
1. 파일을 읽고 핵심 내용 파악
2. 관련 wiki/ 페이지에 내용 추가 또는 새 페이지 생성
3. 위키링크로 관련 페이지 연결
4. `_Index.md` 업데이트

### 2. QUERY (질의응답)
질문을 받으면:
1. 관련 wiki/ 페이지 탐색
2. 위키 내용을 근거로 답변 합성
3. 좋은 답변은 wiki/에 새 인사이트로 저장

### 3. LINT (위키 검증)
주기적으로 실행:
1. 모순되거나 오래된 정보 탐지
2. 누락된 위키링크 연결
3. 빈 페이지 또는 stub 페이지 보완
4. `_Index.md` 정합성 확인

## lint 루틴

**실행 시점 (둘 중 하나)**
1. 매주 월요일 새 대화 시작 시 → "lint 해줘"로 시작
2. ingest 3회 누적 후 → ingest 완료 보고 시 lint 권장 알림 포함

**lint 트리거 조건** (자동 감지):
- 마지막 lint 날짜가 7일 이상 경과한 상태에서 ingest가 실행될 경우
  → ingest 완료 후 "⚠️ 마지막 lint: N일 전 — lint 실행을 권장합니다" 안내

## 작업 시작 방법
새 대화에서 Claude Code를 통해:
- `ingest` — raw/에 새 파일 추가 후 실행
- `query "질문"` — 위키 기반 질의응답
- `lint` — 위키 전체 점검
