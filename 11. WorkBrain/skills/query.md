# QUERY — 위키 기반 질의응답 커맨드

wiki/ 페이지를 근거로 질문에 답변하고, 좋은 답변은 다시 위키에 저장한다.

## 실행 전 준비

### Step 0: 인덱스 먼저 확인
```
11. WorkBrain/wiki/_Index.md    ← 전체 페이지 목록 파악
```

## 처리 로직

### Step 1: 질문 분석
- 어느 카테고리가 관련있는가?
  - 나 자신, 해운/영업, AI/생산성, 커리어 전환
- 어떤 엔티티(사람/회사/프로젝트)가 언급되는가?
- 시간 범위가 있는가? (최근, 과거, 특정 시점)

### Step 2: 관련 Wiki 페이지 탐색
인덱스에서 관련 페이지를 파악한 뒤 순서대로 읽는다:
```
11. WorkBrain/wiki/[카테고리]/[페이지].md
```
- 직접 관련 페이지 우선
- 위키링크로 연결된 페이지도 필요시 추가 탐색

### Step 3: 답변 합성
읽은 위키 내용을 바탕으로 답변 작성:
- **근거 명시**: 어느 페이지의 내용인지 출처 표시
- **추론 분리**: 위키에 있는 사실 vs Claude의 추론을 구분
- **감정 배제**: 위키에 기록된 데이터로만 판단 (객관성 유지)

답변 형식:
```
## [질문 요약]에 대한 답변

### 위키 기반 사실
(wiki/ 페이지에서 직접 발견한 내용)

### 패턴 / 인사이트
(여러 페이지를 종합해서 도출한 분석)

### 근거 페이지
- [[페이지1]]
- [[페이지2]]
```

### Step 4: 답변 저장 여부 판단
다음 조건 중 하나이면 위키에 저장:
- 새로운 인사이트가 도출되었다
- 여러 페이지를 종합한 패턴 발견
- 앞으로 반복적으로 참조할 만한 내용

저장 위치:
- 기존 관련 페이지에 "## 파생 인사이트" 섹션으로 추가
- 또는 `wiki/나-자신/insights-[주제].md`로 신규 생성

## 결과 보고
```
💡 QUERY 완료
- 참조한 페이지: [목록]
- 위키에 저장된 인사이트: [있음/없음]
```

## 한계 인정
위키에 없는 정보는 솔직하게 말한다:
"이 주제에 대한 기록이 아직 wiki에 없습니다. raw/ 폴더에 관련 자료를 추가하고 ingest를 실행하면 다음부터 답변 가능합니다."
