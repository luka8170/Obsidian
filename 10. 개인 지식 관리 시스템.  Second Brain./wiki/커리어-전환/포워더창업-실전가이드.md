# 포워더 창업 실전 가이드

> forwarder.kr 물류자료실의 포워더 창업 시리즈 4편 정리.  
> 법인설립 → 면허 등록 → 협회/EDI → 업무환경 세팅까지 실무 단계별 절차.

---

## 1단계: 법인 설립 + 국제물류주선업 등록

### 창업 전체 흐름
```
법인 설립 → 국제물류주선업(포워더) 면허 신청 → 사업자 등록
```
- 자본금 **6억 이상** 시 개인사업자로도 면허 신청 가능
- 일반적으로는 법인 설립 후 진행

### 법인 설립 요건
| 항목 | 내용 |
|------|------|
| 자본금 | 3억 원 이상 (잔액증명서 필요) |
| 임원 | 이사 1명 이상 (10억 미만 법인 기준) |
| 사무실 | 건축법상 사무용도 적합 (1·2종 근린생활시설 또는 업무시설) |
| 상호 | 동일 지역 내 동일 상호 중복 여부 사전 확인 필수 |

### 국제물류주선업 등록 필수 요건
- **보증보험**: 1억 원 이상 가입 필수  
  (단, 다음 경우 면제: 자본금·자산 10억 이상 / 컨테이너장치장 소유 / 은행 지급보증 1억 이상 / 화물배상책임보험 1억 이상)
- 등록 기관: 시·도지사 (광역지자체)

### 사업자등록 타이밍
- 급하면 면허 전에 다른 업종으로 먼저 사업자등록 후 추후 추가 가능

---

## 2단계: 협회 가입, 세관코드, 포워딩 EDI 등록

### 주요 등록 절차
1. **화물운송주선업 등록** (세관): 전국 어느 세관에서도 신청 가능
   - 등록 완료 시 **세관코드 4자리** 부여
   - 원하는 4자리 사전 신청 가능 (유니패스에서 사전 확인)
2. **협회 가입**: 한국국제물류협회(KIFFA) 등
3. **포워딩 EDI 등록**: 세관코드 확보 후 진행

---

## 3단계: 업무환경 세팅 #1 (포워딩프로그램·사무기기·인터넷)

### 포워딩 프로그램
- 포워딩 전용 ERP/TMS 도입 필요
- 통관·선적·정산 기능 통합 관리

### 사무 기기 기본 세트
- 컴퓨터 + 모니터
- 프린터/복합기 (선하증권, B/L 출력용)
- 인터넷 회선 (안정성 중요)

---

## 4단계: 업무환경 세팅 #2 (복합기·인쇄용지·사무실)

### 사무실 선택 기준
- 건축법상 사무용도 적합 여부 확인 (1·2종 근린생활 또는 업무시설)
- 임대차계약서 주소와 등록 주소 일치 필수

### 인쇄 환경
- B/L, 원산지증명서, 각종 서류 출력 빈도 높음
- A4 용지 대량 확보 + 복합기(프린터+스캐너+팩스) 권장

---

## Luka의 창업 비용 추정 (메모)

| 항목 | 비용 |
|------|------|
| 포워딩 면허(국제물류주선업) | 700~800만원 (대행 포함) |
| 법인 자본금 | 3억 원 이상 필요 |
| 보증보험 | 연 약 100~150만원 수준 |
| 사무실 보증금+월세 | 지역별 상이 |
| 포워딩 ERP | 월정액 SaaS 또는 초기 구축비 |

> 💡 현실적인 최소 창업 비용: **자본금 3억 + 운영비 약 1,000만원**  
> 자본금은 통장에 잠시 입금 후 잔액증명서 발급에 사용 (실제 묶이는 건 아님)
