# LINT — 위키 전체 점검 커맨드

wiki/ 전체를 읽고 품질 문제를 찾아 수정한다.

## 실행 전 준비

```
11. WorkBrain/CLAUDE.md          ← 규칙 재확인
11. WorkBrain/wiki/_Index.md     ← 전체 페이지 목록
```

## 점검 항목

### 1. Stub 페이지 탐지
조건: 내용이 3문장 미만이거나 "추가 예정" 상태
처리: 기존 raw/ 또는 다른 wiki 페이지를 참조해서 내용 보완

### 2. 끊긴 위키링크 탐지
조건: `[[링크]]`가 실제 존재하지 않는 파일을 가리킴
처리:
- 해당 페이지를 새로 생성하거나
- 링크를 올바른 페이지로 수정

### 3. 고아 페이지 탐지
조건: `_Index.md`에는 없는데 wiki/ 폴더에 존재하는 페이지
처리: `_Index.md`에 추가

### 4. 모순 정보 탐지
조건: 두 페이지에서 같은 사실이 다르게 기록됨
(예: 한 페이지에서는 "Sinokor FYF $10K/선", 다른 페이지에서 "$15K/선")
처리:
- raw/ 원본 확인 후 정확한 정보로 통일
- 더 최근 날짜의 정보를 우선

### 5. 오래된 정보 탐지
조건: `updated` 날짜가 90일 이상 된 페이지
처리: 사용자에게 업데이트 필요 여부 알림 (자동 수정하지 않음)

### 6. 누락된 역링크 탐지
조건: A 페이지가 B를 언급하지만 B의 "관련 페이지"에 A가 없음
처리: B 페이지에 A로의 역링크 추가

### 7. _Index.md 정합성 확인
- 실제 wiki/ 폴더의 파일 수 vs 인덱스 페이지 수 일치 여부
- 통계 수치 (페이지 수, raw 파일 수) 최신화

## 결과 보고
```
🔍 LINT 완료 — [날짜]

### 발견된 문제
- Stub 페이지: N개 → [처리 내용]
- 끊긴 링크: N개 → [처리 내용]
- 고아 페이지: N개 → [처리 내용]
- 모순 정보: N개 → [처리 내용]
- 오래된 페이지: N개 → [업데이트 요청 목록]
- 누락 역링크: N개 → [처리 내용]

### 위키 현황
- 총 페이지: N개
- 총 Raw 파일: N개
- 다음 lint 권장일: [날짜 + 30일]
```

## 중요 규칙
- raw/ 파일은 절대 수정하지 않는다
- 내용 삭제보다 보완 우선
- 확신 없는 정보는 수정하지 말고 사용자에게 확인 요청
