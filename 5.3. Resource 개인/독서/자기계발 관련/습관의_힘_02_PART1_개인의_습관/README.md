# 습관의 힘 - PART 1: 개인의 습관

## 📖 내용
- **부제**: 반복되는 행동으로 극적인 변화를 만든다
- **페이지**: 21-146페이지
- **챕터**: 1-3장

### 📝 각 장별 내용

#### 1장: 왜 우리는 후회할 줄 알면서도 똑같은 일을 반복하는가
- 습관에 대한 우리의 지식을 완전히 바꿔 놓은 남자 (유진 폴리 사례)
- 습관 고리: 습관을 구성하는 세 가지 단계 
- 습관은 우리를 어떻게 지배하는가
- 기억은 사라져도 습관은 남는다

#### 2장: 열망 - 새로운 습관은 어떻게 탄생하는가
- 양치질은 어떻게 전 세계인의 습관이 되었나
- 최악의 실패작, 페브리즈
- 우리가 치킨과 감자튀김의 유혹을 거부할 수 없는 이유
- 뜻밖의 열망을 포착한 페브리즈의 반전
- 성공하고 싶다면 열망을 자극하라

#### 3장: 반복 행동 - 습관을 바꾸기 위해 알아야 할 황금률
- 팬들도 포기한 꼴찌를 최강으로 만든 토니 던지 감독의 습관 훈련법
- 알코올 중독자 1000만 명을 치료한 AA의 비밀
- 결정적인 순간에 어김없이 나타나는 옛 습관의 그림자
- 습관 교체 기법: 바뀐 습관을 완전히 내 것으로 만드는 법
- 삶의 방식을 바꾼 사람들의 공통점

## 🎯 핵심 메시지
개인의 습관이 어떻게 형성되고, 어떤 메커니즘으로 작동하며, 어떻게 바꿀 수 있는지에 대한 과학적 근거와 실용적 방법을 제시합니다.
