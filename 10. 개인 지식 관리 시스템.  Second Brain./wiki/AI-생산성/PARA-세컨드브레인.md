# PARA Method — 티아고 포르테

## 핵심 내용

PARA는 디지털 지식을 **현재 실행 가능성**을 기준으로 분류하는 4단계 시스템.

| 카테고리 | 정의 | 예시 |
|---------|------|------|
| **P**roject | 구체적 마감일이 있는 현재 목표 | Sinokor VLCC 계약, 관세사 시험 |
| **A**rea | 지속적으로 유지해야 할 책임 영역 | 고객 관리, 건강, 가족 |
| **R**esource | 미래에 참고할 수 있는 정보 | 기술 자료, 업계 정보 |
| **A**rchive | 완료/비활성 항목 | 끝난 프로젝트, 구 자료 |

## 핵심 인사이트

1. **출처/형식 기준이 아닌 "행동 가능성" 기준으로 분류**
   - 기존: "이건 해운 자료니까 해운 폴더에"
   - PARA: "이게 지금 나에게 필요한가? → Project인가, Resource인가?"
   - 정보를 저장하는 뇌가 아닌 **행동하는 뇌**로 전환

2. **프로젝트 ≠ 목표, 프로젝트 = 마감이 있는 행동 단위**
   - "건강해지기"는 Area, "5월 30일까지 5kg 감량"은 Project
   - Luka에게: "관세사 취득"은 Area, "2026 1차 시험 합격"은 Project

3. **세컨드 브레인의 3단계 원칙**
   - Capture: 들어오는 모든 정보를 신뢰할 수 있는 외부 시스템에 저장
   - Organize: PARA로 분류
   - Distill & Express: 정제하고 생산으로 연결

## Luka 현재 시스템과의 매핑

| Luka 볼트 | PARA |
|----------|------|
| `1. Project/` | Project |
| `2. Area/` | Area |
| `3. Resource/` | Resource |
| `4. Archive/` | Archive |
| `5.x 개인/` | 개인 PARA |

→ **이미 PARA 구조로 되어 있음!** 실행 포인트는 "프로젝트 목록을 항상 최신화"하는 것

## 적용 액션

- [ ] 매주 월요일 Project 목록 검토 (완료된 것 Archive로, 새 것 추가)
- [ ] Raw 노트 → 즉시 PARA 분류 (Second Brain 내 daily ingest 습관화)
- [ ] Second Brain 위키 자체도 PARA 원칙으로 유지
