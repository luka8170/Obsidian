# 린 스타트업 실전 — 비즈니스 모델 캔버스 + 린 캔버스

## 핵심 개념

**린 스타트업** = 에릭 리스. "승리하는 유일한 방법은 다른 누구보다 빨리 배우는 것"
- 아이디어 → **Build(MVP)** → **Measure(측정)** → **Learn(학습)** → 반복

## 비즈니스 모델 캔버스 9블록

| 블록 | 핵심 질문 |
|------|---------|
| 고객 세그먼트(CS) | 누구를 위한 가치인가? |
| 가치 제안(VP) | 어떤 문제를 해결하는가? |
| 채널(CH) | 어떻게 전달하는가? |
| 고객 관계(CR) | 어떻게 관계를 유지하는가? |
| 수익원(RS) | 어떻게 돈을 버는가? |
| 핵심 자원(KR) | 무엇이 필요한가? |
| 핵심 활동(KA) | 무엇을 해야 하는가? |
| 핵심 파트너십(KP) | 누구와 협력하는가? |
| 비용 구조(CS) | 비용은 어디서 발생하는가? |

## 린 캔버스 vs 비즈니스 모델 캔버스 차이

- **비즈니스 모델 캔버스**: 기존 기업 + 창업 기업 모두 적용, 고객-채널-관계 중심
- **린 캔버스**: 창업 기업 전용, **문제 → 해결책 → MVP** 중심, 일방적 경쟁우위 추가

## 린 캔버스 핵심 추가 블록

- **문제(Problem)**: 고객이 겪는 상위 3가지 문제
- **해결책(Solution)**: 문제별 최소 기능 (MVP 수준)
- **핵심 지표(Key Metrics)**: 성공 측정 지표 (AARRR: 유치-활성-유지-매출-추천)
- **일방적 경쟁우위(Unfair Advantage)**: 돈으로 살 수 없거나 복제 불가한 것

## Luka 물류 스타트업 적용

린 캔버스 관점에서 Luka의 **최대 경쟁우위**:
- 25년 해운/선주/기자재 업계 핵심 네트워크 → 복제 불가
- BV 재직 중 구축한 선사 관계 → 즉시 공급 파이프라인 활용 가능
- 책임 있는 클레임 대응 경험

**MVP 원칙**: 전체 플랫폼 개발 전 "지인 화물 우선 진행"으로 먼저 수익 검증
