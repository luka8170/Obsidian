## 배경 및 사전 맥락

- 하나마린은 기존 주력 선급이 **KR**이었으며, BV 전환 후 검사비 수준에 대한 누적 불만 존재
- 2024년 4월 이후 검사비 납부가 지연되기 시작 → 미수금 적체로 BV 내부 강한 독촉(push) 수신 중
- 미수금 발생 배경: 검사비 과다 인식 + 내부 결재 지연 + 인보이스 일부 미수신 복합 요인
- 점심 중 양측 간 긴장감 해소 후, 사무실에서 본격적인 기술·비용 협의 진행

- 8척 중 4척이 파나마 국적 (에이스하나, 케마나, 미르하나 등) → 해당 선박들에서 불만 집중
- 한국 국적 4척(우리하나, 칠하나, 프리티, 루나하나)은 상대적으로 금액이 낮아 큰 이슈 없음

### BV 설명

- **한국 국적 선박**: 해수부와 합의된 수수료 상한이 있어 인보이스에 "Agreed MF / Discount" 명기 → 코리아 플래그 자동 할인
- **파나마 국적 선박**: 해수부 합의 적용 불가 → 본사 표준 타리프 기준 적용 + 재량 내 DC
- BV 본사가 각국 DC 수치를 모니터링 → 강 선생님 재량 제한적
- Luka 2018년 매니저 취임 이후 파나마 선박에도 최대한 할인 적용 중

### 검사비 수용 가능 범위 협의 (비공개)

- **DP님 → Luka 전달**: "KR의 150% 이내라면 수용 가능"
- **하나마린 내부 실제 허용선**: 강 소장님 발언 — "130% 정도면 OK"라고 서울 보고, 실제 허용 상한 50% up (1.5배)
- Luka가 서울(본사)에 보고한 수치: "30% 이내" → 실제보다 보수적으로 보고
- **BV 내부 판단**: 현재 검사비 수준이 KR 1.5배 기준과 크게 다르지 않으나, 개별 항목에서 2배 초과 사례 존재 (케마나 전기검사 등)

### 향후 협의 방향

- BV 내부 검토 후 회신 예정 (결정권: BV Korea 대표 → 본사 체인 필요)
- 인보이스 분할 납부 가능성 언급 (Luka 확인 필요)
- 강 선생님: "블록계약 체결 시 별도 협의 가능" 여지 있으나 확답 불가
- 탈급(de-classing) 가능성: DP님이 이미 내부 검토 중임을 비공식 공유 → Luka도 인지

> ⚠️ **Action Item (Luka):** BV 내부에서 검사비 조율 가능 여부 검토 후 회신. 케마나 3,100만 원 인보이스 미수신 건 확인 및 재발송.

## 3. PSC 동행검사 서비스 요청 및 BV 대응

### 배경

- 과거 사례: BV 선급 선박에 PSC 지적이 있었을 때, BV 감독 부재 상황에서 다른 감독이 KR에 연락 → KR이 대신 대응
- 이 사례가 "BV는 연락해도 안 오고, KR은 연락하면 바로 온다"는 인식으로 굳어짐 (2~3년 전 사건)
- 하나마린 현재 선박: 신조 후 7년 경과 → 향후 노후화 시 PSC 문제 증가 우려
- KR은 사실상 "감독 대행" 수준의 PSC 동행 서비스 → BV에도 동일 수준 요구

### BV 입장

- **BV의 공식 서비스 범위**: PSC 동행검사(감독 대행) 서비스는 제공 불가 — 선급의 공식 업무 범위 초과
- KR의 해당 서비스는 해수부 갑질 관계에서 비롯된 비정상적 확장 서비스
- BV 내부에서도 해수부와 이 부분 조율 중 (한국 정부 대행 검사 지속 필요성 논의)

### 대안: Pre-PSC Inspection 서비스

- BV가 공식 제공하는 서비스
- PSC 민감 항목 체크리스트 기반 사전 점검
- 해당 포트의 BV 로컬 검사관이 방문 → PSC 인스펙터와 커뮤니케이션 가능
- PSC 인스펙터가 와서 이미 BV 검사 진행 중인 것을 목격하면 형식적으로 넘어가는 심리적 효과 기대
- 포트마다 가격 상이 (로컬 기준으로 문의 필요)
- 블록계약에 Lump Sum으로 포함 가능 여부 → Pre-PSC Inspection은 예측 불가 항목이라 블록 포함 어렵다는 BV 설명

### Luka 조치 사항

- 일본 NS Japan, 카노상에게 하나마린의 우려 전달 완료 ("현재는 문제없으나 향후 대비 신경 써달라")

> ✅ **Action Item (Luka):** Pre-PSC Inspection 서비스 포트별 요금 안내 자료 하나마린에 제공.

## 4. 일본 NC 신조 프로젝트 — 히로시마 **홍카와라(Hongawara)** 조선소

### 배경

- 하나마린 일본 신조 NC 프로젝트 존재 (박 대표님 확인, 조선소명 비공개였으나 Luka가 "홍카와라" 언급 시 박 대표님이 반응하여 확인됨)
- 하나마린: 5척 발주 희망 → 조선소로부터 3척 거부 → 현재 2척 논의 중
- 딜리버리 시점이 핵심 이슈 — 원하는 일정 확보 어려운 상황
- 선가(조선가) 급등으로 발주 지연되었다가 본격 재검토 중

### 선급 이슈

- **조선소 선호**: NK (닛폰카이지)
- **하나마린 선호**: BV 또는 KR (한국 BBCHP 적용 시 정부 대행 검사 필요 → BV 또는 KR 유리)
- 조선소의 BV 거부 표면적 이유: "기자재 BV 인증 부족"
  - BV Japan 확인 결과: MO(기국) 기준 적용 시 전혀 문제없음 → 기술적 이유 아님
- **조선소의 실제 이유 (마지막에야 공개)**: **검사비 차이**
  - 히로시마 지역에 BV/KR 고정 사무소 없음 → 타지 출장 검사 → 출장비 포함 비용 높음
  - NK는 히로시마, 후쿠오카 등 전국에 지점 보유 → 현장 근거리 검사 가능 → 비용 낮음
  - 조선소가 신조 기자재 검사비를 부담하므로 NK 선호

### 향후 대응

- 조선소의 실제 이유(검사비)를 박 대표님이 사전에 인지하지 못했음 → Luka가 이 정보를 활용하여 BV Japan에 전달 예정
- BV Japan(담당: 카노상 또는 관련 조직)에 히로시마 조선소 검사비 경쟁력 개선 가능 여부 문의
- 하나마린 측이 NK에 "한국법 이행 필요 항목"을 알려주면 NK가 직접 처리하겠다는 입장 → BV/KR 없이 진행할 가능성 존재

> ✅ **Action Item (Luka):** BV Japan에 홍카와라 조선소 검사비 이슈 전달. 경쟁력 있는 수준 제시 가능 여부 확인.
> ⚠️ **리스크**: 조선소 주도로 NK 선정 시 BV 참여 기회 소멸. 하나마린 영업적 개입 필요.

## 5. BBCHP / 한국 정부 대행 검사 요건 리스트

- 하나마린이 일본 신조선을 BBCHP(나용선)로 인수 시 **한국선박안전법** 적용
- 딜리버리 시점에 TOC 할 때 미비사항 발견 시 딜리버리 지연 위험
- 하나마린 요청: BV가 **한국법 요구 도면/서류 리스트** 사전 제공 → 조선소(NK)와 협상 레버리지로 활용
- BV 답변:
  - 리스트 작성 가능, 대외 기밀 아님
  - 다만 범위가 방대하므로 핵심 포인트 위주 효율적 정리 필요
  - BV NC팀에 내부 문의 후 진행
  - 코리아 플래그(한국 법정검사) 적용 vs 미적용 차이 항목만 추려도 효과적

> ✅ **Action Item (Luka):** NC/신조 한국 정부 대행 검사 요구사항 리스트 작성 → 하나마린 제공. BV NC팀 내부 문의 선행.
