- 수행평가 비중 30~40%, 암기식·과제형 수행평가는 금지되어 발표·토론·글쓰기·실험실습·프로젝트 중심으로 전환 중 → 벼락치기가 통하지 않는 구조

## 2. 영재학교 vs 과학고 — 전형 구조 비교

| 구분 | 영재학교 (8개교: 서울·경기·대전·대구·광주과고, 세종·인천 과학예술영재학교, KSA) | 과학고 (20개교) |
|------|---|---|
| 법적 지위 | 영재교육진흥법 적용, 특목고 아님 | 특목고 |
| 전형 시기 | 중3 초, 4~9월 (원서접수 4~5월 → 서류 → 영재성검사/창의적 문제해결력평가 7월 → 영재성캠프 8월 → 발표 8~9월) | 중3 하반기, 9~11월 (자기주도학습전형) |
| 평가 방식 | 서류 + 지필고사(수학·과학 사고력 문제) + 1박2일 캠프(실험·관찰·면접) | 서류(학생부) + 소집면접, 지필고사 없음 |
| 실질 준비 강도 | 지필고사가 있어 심화 수학·과학 사고력 훈련이 사실상 필요 (고1 수준 수학까지 다루는 경우 많음) | 학생부·면접 중심, 학교생활 충실도 비중이 큼 |
| 규제 | 수학경시대회 수상실적·외부 인증시험 결과 기재 금지, 면접에서 선행학습 여부 직접 평가 안 함 → 실질 평가는 "학교 수업에서 무엇을 탐구했는가" | 동일 |

### 이원 트랙 전략 — "영재학교 우선 지원, 탈락 시 과학고"
영재학교 전형이 과학고보다 먼저 끝나므로, **영재학교에 먼저 지원 → 탈락 시 같은 해 하반기 과학고 자기주도학습전형 지원**이 일정상 가능하다. 즉 "영재학교 아니면 실패"가 아니라, 영재학교 수준까지 끌어올려 놓으면 과학고는 자연히 따라오는 구조로 준비하면 된다.

## 3. 통합 타임라인

**초6 (~2027년 2월)**
- 수학: 중3 전 과정 완주 목표 유지
- 과학: 물리 마무리 → 화학 진입 검토 (몰 개념·화학반응식은 수학적 계산력 필요, 지금 수학이 앞서 있어 타이밍 나쁘지 않음)
- 교육청 영재교육원 / 대학부설 영재교육원 지원 검토 (초6~중1 지원 가능, 두 트랙 모두에 도움)
- 독서·글쓰기·자기주도학습 습관 유지 (서·논술형 대입 개편 대응의 공통 기반)

**중1 (2027년)**
- 자유학년제(시험 없음) 기간을 탐구활동·과학 동아리·영재교육원에 집중 투자
- 수학: 고1 수학 + 중등 심화 병행, 중2 말까지 고1 수준 안정화가 목표
- 과학: 생명과학·지구과학 순차 진입, 병행 노출 시작 (뒤로 미루지 않기)
- 목표 영재학교·과학고 후보 각 2~3곳 리스트업
- 교과 교사 이름 기억, 전 과목 성실한 수업 태도 (세특 관리의 시작점)

**중2 (2028년)**
- **분기점**: 상반기~중반 수학·과학 성취도와 사고력 문제 해결 능력을 냉정히 점검해 영재학교 지필고사 도전 여부 판단
- 수학·과학 내신 최상위권 유지 (두 과목 모두 A 목표, 특목고 지망 시 C 하나도 치명적)
- 학생부에 남길 탐구활동(실험, 프로젝트, 소논문 형태) 본격 축적 — "2학년 2학기에 몰아서 채우는 건 불가능"
- 국어·사회 등 문과 과목 서·논술형 수행평가도 소홀히 하지 않기

**중3 (2029년)**
- 4~5월 영재학교 원서접수 → 7월 지필고사 → 8월 영재성캠프 → 8~9월 발표
- 불합격 시 9~11월 과학고 자기주도학습전형 준비·지원 (학생부·면접 대비 그대로 활용)
- 면접·캠프 평가는 "중학교 교육과정 내 사고력·창의성을 말로 표현하는 능력"을 봄 — 대입 개편 방향("정답 맞히기 → 사고 과정 표현하기")과 동일한 결

## 4. 수학 학습 체크포인트 (진도 vs 이해)

"진도는 빠르게 훑고, 심화는 되돌아가서 깊게"는 영재고 준비생들의 정석 전략이나, 속도 자체가 빠른 만큼 이해가 진도를 못 따라가지 않도록 확인 장치가 필요하다.

1. **중3 완주 시점(2027년 2월) 총괄 진단평가**: 단원별 소테스트가 아니라 중1~중3 전 범위를 섞은 종합 시험으로 정착 여부 확인. 구멍이 보이면 고1 진입을 2~3주 늦추더라도 메우고 갈 것.
2. **고1 수학 진도는 계산 숙련에 그치지 않기**: 단원 하나 끝날 때마다 개념을 말로 설명해보게 하는 루틴 (기존 [[2026-중등완주-고등1등급-로드맵]]의 백지테스트·공식 증명 원칙과 동일 맥락).
3. **중학 심화는 '오답 원인 분석' 중심**: 새 유형 습득이 아니라, 어려운 문제를 틀렸을 때 "어느 개념을 놓쳤는지" 스스로 적어보는 루틴. 이것이 영재성검사(창의적 문제해결력평가)가 요구하는 "낯선 문제를 개념에서부터 다시 풀어내는 힘"을 기르는 과정.

## 5. 과학 균형 전략

수학과 달리 과학은 진도보다 **실제로 실험하고 관찰한 경험 자체**가 실력이자 학생부 소재다. 영재성캠프의 관찰평가(직접 실험·조작하며 사고 과정을 보여주는 단계)에서 개념만 아는 것과 실제 경험이 있는 것은 크게 차이 난다.

- 대부분 영재학교 지필고사는 **물리·화학 비중이 특히 크고**, 서류·캠프 단계에서는 생명과학·지구과학 포함 4개 영역을 폭넓게 다뤄본 경험이 소재가 됨 — 한쪽만 깊이 파고 나머지를 손 놓으면 편식이 드러남
- 순서 제안: 물리(진행 중) → 화학(수학이 앞서 있어 타이밍 좋음) → 생명과학·지구과학(암기 비중 크다고 뒤로 미루지 말고 지금부터 주 1~2회 병행 노출)
- 개념 진도와 별개로 **실험/탐구 경험**을 지금부터 쌓기: 영재교육원 과학반, 과학관 탐구 프로그램, 간단한 실험 키트, 자유연구 형태의 소논문 시도
- 타임라인: 중1 말~중2 초까지 4개 영역 중등 과정 완료 → 중2에 심화 + 실험 경험 집중 (수학보다 완주 시점을 다소 늦게 잡되, 진도보다 "직접 해보는 경험의 누적"을 목표로 삼을 것)
