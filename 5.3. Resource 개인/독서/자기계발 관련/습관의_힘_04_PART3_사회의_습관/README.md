# 습관의 힘 - PART 3: 사회의 습관

## 📖 내용
- **부제**: 절대 바뀌지 않는 세상을 바꾸는 힘
- **페이지**: 257-377페이지
- **챕터**: 8-9장

### 📝 각 장별 내용

#### 8장: 사회 변화는 어떻게 일어나는가 - 시민권 운동과 새들백 교회
- 미국을 뒤흔든 시민권 운동의 시작
- 사회 변화를 일으키는 약한 연대의 힘
- 사회적 습관을 활용해 미국 최고의 교회가 된 새들백 교회

#### 9장: 습관을 바꾸기 위해 가장 먼저 해야 할 것 - 도박 중독자와 몽유병 환자의 차이
- 도박에 빠진 평범한 어느 주부의 고백
- 사랑하는 아내를 살해한 몽유병 환자
- 거부할 수 없는 습관의 유혹
- 습관을 바꾸기 위해 가장 먼저 해야 할 것

## 🎯 핵심 메시지
사회 전체의 습관이 어떻게 형성되고 변화하는지, 그리고 개인의 책임과 습관 변화의 관계에 대해 다룹니다. 마틴 루서 킹의 시민권 운동과 같은 거대한 사회 변화도 습관의 힘으로 설명할 수 있음을 보여줍니다.
