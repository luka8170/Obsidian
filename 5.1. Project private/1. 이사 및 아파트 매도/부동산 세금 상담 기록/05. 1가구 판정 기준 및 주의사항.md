# 1가구 판정 기준 및 주의사항

## 핵심 질문
부모님께 2억 주택을 증여한 후 20억 주택 매각 시, 2가구 주택 불이익은 없나?

## 세법상 "1가구" 판정 기준

### 주택 수 계산 시 가구 범위 (소득세법 시행령 제155조)

1. **배우자** - 항상 1가구로 봄
2. **동거 가족** - 생계를 같이하면 1가구
3. **별거 부모** - 원칙적으로 별도 가구

## 부모님이 별도 세대인지가 관건!

### Case 1: 부모님이 별도 세대 (따로 거주) ✅
- 본인 가구: 20억 주택만 → 1가구 1주택 ✅
- 부모님 가구: 2억 주택 → 별도 가구
- 20억 매각 시: 1가구 1주택 비과세 적용 가능!

### Case 2: 부모님과 동거 중 (같이 거주) ❌
- 1가구: 20억 + 2억 → 여전히 1가구 2주택 ❌
- 20억 매각 시: 2주택 중과세 적용
- 증여한 의미 없음!

## 별도 가구 인정 조건

### 필수 조건 (모두 충족 필요):

1. **주민등록상 세대 분리**
   - 부모님이 다른 주소지에 등재
   - 주민등록표 기준

2. **실제로 따로 거주**
   - 생계를 별도로 함
   - 형식적 분리만으로는 안 됨

3. **독립적 생활 유지**
   - 경제적으로 독립
   - 실제 별도 거주의 실질

### 동일 가구로 보는 경우 ❌:

1. 주민등록상 같은 세대
2. 실제 같이 거주
3. 생계를 같이 함 (경제공동체)
4. 형식적으로만 분리 (세무서 추징 위험!)

## 실무상 검증 방법

### 세무서 판단 기준: 실질과세 원칙

**위험한 케이스:**
- ❌ 같은 아파트 다른 호수로 주민등록 이전
- ❌ 부모님 명의로 전입했지만 실제 동거
- ❌ 생활비/의료비 등을 자녀가 전액 부담
- ❌ 증여 직전에 급하게 세대 분리

→ 조세회피 목적으로 판단될 위험!

## 시나리오별 대응 전략

### 시나리오 A: 부모님이 이미 별도 거주 중 ✅

**완벽한 상황!**
1. 1월: 2억 주택 증여 → 즉시 1가구 1주택 전환
2. 하반기: 20억 주택 매각 → 1주택 비과세 적용
3. 총 세금: 약 1.2~2.2억원

### 시나리오 B: 부모님과 현재 동거 중 ⚠️

**문제 있음!**

**Option 1: 부모님 먼저 분가시키기**
- 실제 다른 곳으로 이주
- 6개월~1년 경과 후 증여
- 실질적 별도 가구 인정받기

**Option 2: 2억 주택 그냥 매각**
- 양도세 2~3천만원 부담
- 확실한 1가구 1주택 전환

### 시나리오 C: 형식적 분리 계획 중 ❌

**매우 위험!**
- 같은 아파트 다른 호수로 이전
- 세무조사 시 추징 위험
- 가산세 + 중과세 소급 적용

**차라리 정직하게:**
- 2억 매각 + 양도세 부담
- 또는 부모님 실제 분가 후 충분한 시간 경과

## 세무서 조사 시 입증 자료

### 별도 가구임을 입증하려면:

1. **주민등록등본** (세대 분리 확인)
2. **공과금 고지서** (실제 거주 증명)
3. **부모님 소득자료** (경제적 독립)
4. **건강보험 자격득실확인서** (세대주 확인)
5. **통신비/관리비 납부 내역** (실거주 증명)
