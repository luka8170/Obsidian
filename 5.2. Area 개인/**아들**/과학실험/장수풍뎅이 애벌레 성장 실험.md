
# 🐛 장수풍뎅이 애벌레 성장 실험

## 🤔 우리가 알아보고 싶은 것

**“땅콩을 많이 먹은 장수풍뎅이 애벌레가 더 빨리 클까?”**

-----

## 💡 우리의 예상 (가설)

**땅콩을 더 많이 섞어준 톱밥에서 자란 애벌레가 더 빨리 자랄 것이다!**

왜냐하면 땅콩에는 애벌레가 자라는 데 필요한 단백질과 영양분이 많이 들어있기 때문이에요.

-----

## 🔬 실험 방법

### 1단계: 실험 준비하기

- 같은 크기의 건강한 장수풍뎅이 애벌레 준비하기
- 두 개의 사육통 준비하기
- 톱밥과 갈은 땅콩 준비하기

### 2단계: 두 그룹 만들기

**🥜 A그룹**: 톱밥 + 땅콩 800g
**🥜 B그룹**: 톱밥 + 땅콩 1400g

### 3단계: 애벌레 관찰하기

- 매주 같은 요일에 애벌레 크기 재기
- 몸무게와 길이 측정하기
- 얼마나 활발한지 관찰하기

### 4단계: 기록표 작성하기

-----

## 🎯 실험할 때 주의사항

- 두 그룹 모두 같은 온도와 습도에서 키우기
- 같은 시간에 관찰하고 측정하기
- 애벌레를 다룰 때는 부드럽게 조심스럽게!
- 매일 먹이 상태 확인하기
