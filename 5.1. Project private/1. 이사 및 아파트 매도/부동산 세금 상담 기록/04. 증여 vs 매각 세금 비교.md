# 증여 vs 매각 세금 비교

## 핵심 차이점: "매각"과 "증여"의 차이

### 1. 부모님께 "매각"하는 경우
```
아들 → 부모님께 2억에 "매매"
```
**양도세 발생:**
- ✅ 양도세 내야 함
- 2주택 상태에서 매각이므로 중과세 적용
- 취득가 1억, 매도가 2억이면
- 양도차익 1억 × 중과세율 = 약 2,000~3,000만원

❌ **이 방법은 별 의미 없음** (시장에 파는 것과 동일한 세금)

### 2. 부모님께 "증여"하는 경우
```
아들 → 부모님께 2억 주택 "증여"
```
**양도세 없음!**
- ✅ **증여는 양도가 아님!**
- ✅ 양도소득세 발생 안 함
- ✅ 대신 증여세만 납부

**이게 핵심 차이입니다!**

## 세금 구조 비교

### [방법 1] 2억 주택 시장에 매각 + 20억 매각
```
2억 주택 매각:
- 양도세: 2,000~3,000만원 (2주택 중과)

20억 주택 매각:
- 1주택 전환 후 매각
- 양도세: 1~2억원 (12억 초과분)

총 세금: 약 1.2~2.3억원
```

### [방법 2] 2억 주택 부모님께 증여 + 20억 매각 ✅
```
2억 주택 증여:
- 양도세: 0원 (증여는 양도 아님!)
- 증여세: 1,500만원
- 취득세: 700만원
- 소계: 2,200만원

20억 주택 매각:
- 1주택 전환 후 매각
- 양도세: 1~2억원 (12억 초과분)

총 세금: 약 1.2~2.2억원
```

**결과: 거의 비슷하거나 증여가 조금 더 유리!**

### [방법 3] 2주택 상태로 20억 먼저 매각 ❌
```
20억 주택 매각:
- 2주택 중과세 적용
- 양도세: 5~7억원 😱

2억 주택 매각:
- 1주택으로 나중에 매각
- 양도세: 적거나 없음

총 세금: 약 5~7억원
```

## 왜 증여가 유리한가?

### 증여의 세법상 특징
```
[양도] = 돈 받고 팔기
→ 양도소득세 과세 대상
→ 2주택이면 중과세

[증여] = 무상 이전
→ 양도소득세 과세 대상 아님!
→ 대신 증여세만 부과
→ 증여세는 중과 없음
```

### 구체적 계산 예시

**2억 주택 (취득가 1억, 시가 2억)**

**Case A: 시장에 매각**
```
양도차익: 1억
2주택 중과세율: 약 60~70% (기본+중과+지방세)
양도세: 6,000~7,000만원
```

**Case B: 부모님께 증여**
```
증여가액: 2억
증여공제: 5,000만원
과세표준: 1.5억
증여세율: 10~20%
증여세: 1,500만원 + 취득세 700만원 = 2,200만원
```

**절감액: 4,000~5,000만원!**

## 타이밍 전략

### 증여를 선택한다면 ✅

**최적 시나리오:**
```
2025년 1월: 부모님께 2억 주택 증여
- 양도세: 0원
- 증여세: 1,500만원
- 취득세: 700만원

2025년 2월~: 1가구 1주택 상태 확정

2025년 하반기: 20억 주택 매각
- 1주택 비과세 요건 확인
- 12억 초과분 과세
```

**총 세금 부담: 약 1.2~2.2억원**

### 매각을 선택한다면

```
2025년 상반기: 2억 주택 급매
- 양도세: 2,000~3,000만원 부담

2025년 하반기: 20억 주택 매각
- 1주택 전환 후 매각

총 세금 부담: 약 1.2~2.3억원
```

**결과: 거의 비슷함**

## 증여 vs 매각 선택 기준

### 증여가 더 유리한 경우:
1. ✅ **2억 주택이 정말 안 팔릴 때** (현재 상황!)
2. ✅ 양도차익이 큰 경우 (취득가 대비 많이 올랐을 때)
3. ✅ 부모님이 무주택자로 취득세 감면 가능할 때
4. ✅ 시간이 촉박할 때 (매각 기다릴 여유 없음)

### 매각이 더 유리한 경우:
1. 양도차익이 적은 경우 (거의 본전)
2. 부모님이 이미 주택 소유 중
3. 형제자매와 상속 갈등 우려
4. 매각이 곧 가능한 상황

## 실전 조언

### 귀하의 상황에서는:

**"2억 주택이 안 팔린다"** = 증여가 답! ✅

**이유:**
1. ✅ 시간 낭비 없음 (바로 1주택 전환)
2. ✅ 양도세 0원 (vs 매각 시 2~3천만원)
3. ✅ 증여세 부담이 양도세보다 작음
4. ✅ 올해 안에 20억 매각 목표 달성 가능

### 주의사항

**증여 시기:**
- 가급적 연초에 (연말 증여는 다음해로 미룰 수도)
- 증여 후 바로 1가구 1주택 효과 발생

**부모님과 사전 협의:**
- 증여세 누가 낼지 (자녀가 대납 가능)
- 향후 상속 계획
- 형제자매 있으면 양해 구하기

## 최종 답변

**"부모께 양도하면 양도세를 많이 내는게 마찬가지가?"**

### 답:
- **매각(양도)하면**: 양도세 내야 함 (마찬가지)
- **증여하면**: 양도세 안 냄! (증여세만 냄) ✅

**증여가 정답입니다!**
