DCS/MRV 리포팅 기능이 대폭 개편된 릴리스로, 신규 "Fleet: DCS/MRV Reporting" 탭, 서베이어의 리포팅 기간 승인/반려(Reject/Validate) 기능, 클라이언트-BV 리뷰어 간 채팅 기능, 이상 데이터 색상 표시 등이 추가되었고 API 데이터 구조도 OVD 3.9로 업그레이드되었습니다.
