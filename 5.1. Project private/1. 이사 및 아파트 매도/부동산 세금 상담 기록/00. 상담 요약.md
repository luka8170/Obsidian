# 부동산 세금 상담 요약

## 상담 날짜
2026-01-08

## 상담자 상황
- **보유 주택**: 1가구 2주택
  - 배우자 명의: 20억원 (고가 주택)
  - 본인 명의: 2억원 (저가 주택)
- **문제점**: 
  - 2억 주택이 시장에서 안 팔림
  - 20억 주택을 올해 안에 매각 필요
  - 2주택 중과세 부담
- **초기 고민**: 서류상 이혼 고려

## 상담 결과

### 1. 가장이혼 방안 → ❌ 절대 불가
**위험 요소:**
- 조세포탈 혐의 (형사처벌 가능)
- 재산분할청구 위험
- 재혼 거부 시 대응 불가
- 양육권 분쟁 가능성
- 상속권 소멸

**결론**: 법적 리스크가 너무 커서 절대 권장하지 않음

### 2. 배우자 간 증여 방안 → ❌ 의미 없음
**이유:**
- 부부는 항상 1가구로 봄
- 명의만 바꿔도 여전히 1가구 2주택
- 중과세 회피 불가

### 3. 2억 주택 먼저 매각 방안 → △ 가능하나 현실적 어려움
**장점:**
- 정석적인 방법
- 합법적

**단점:**
- 2억 주택이 안 팔림 (현실적 문제)
- 양도세 2~3천만원 부담
- 시간 지연

### 4. 부모님께 증여 방안 → ✅ 최적 해결책

**구조:**
```
1단계: 2억 주택을 부모님께 증여
- 증여세: 1,500만원
- 취득세: 700만원
- 합계: 2,200만원

2단계: 1가구 1주택 상태 확정
- 즉시 효과 발생

3단계: 20억 주택 매각
- 1주택 비과세 적용
- 12억 초과분만 과세
- 예상 양도세: 1~2억원

총 세금: 약 1.2~2.2억원
```

**vs 2주택 상태로 20억 매각:**
- 예상 양도세: 5~7억원

**절감액: 3~5억원!**

## 핵심 포인트

### 증여가 매각보다 유리한 이유:
1. **양도세 0원**: 증여는 양도가 아니므로 양도세 없음
2. **증여세만 부담**: 2,200만원 (양도세 2~3천만원보다 유사하거나 적음)
3. **즉시 효과**: 시장 매각 기다릴 필요 없음
4. **목표 달성**: 올해 안에 20억 매각 가능

### 매각 vs 증여 비교:
| 구분 | 양도세 | 증여세 | 취득세 | 합계 | 속도 |
|------|--------|--------|--------|------|------|
| 시장 매각 | 2~3천만원 | 0 | - | 2~3천만원 | 느림 |
| 부모 증여 | **0원** | 1,500만원 | 700만원 | 2,200만원 | **즉시** |

## 중요 주의사항

### ⚠️ 1가구 판정 기준 확인 필수!

**부모님과의 관계:**
- ✅ **별도 거주 중** → 증여 효과 있음 (별도 가구 인정)
- ❌ **동거 중** → 증여 의미 없음 (여전히 1가구 2주택)

**별도 가구 인정 조건:**
1. 주민등록상 세대 분리
2. 실제로 따로 거주
3. 경제적 독립
4. 생계 별도

**위험한 경우:**
- 같은 아파트 다른 호수 이전
- 형식적 세대 분리만
- 증여 직전 급하게 분리
→ 조세회피로 판단되어 추징 위험!

## 실행 계획

### 필수 확인 사항:
1. [ ] 부모님 현재 거주 상황 확인
2. [ ] 주민등록 세대 구성 확인
3. [ ] 부모님 경제적 독립 여부 확인
4. [ ] 20억 주택 비과세 요건 확인 (보유·거주기간)

### 실행 단계:
1. **세무사 상담** (정확한 세금 계산)
2. **가족 협의** (부모님, 배우자, 형제자매)
3. **증여 실행** (1월 중 완료 권장)
4. **20억 매각 준비** (1주택 상태 확정 후)

## 예상 결과

### 성공 시나리오:
- 총 세금 부담: 약 1.2~2.2억원
- 절감액: 3~5억원
- 가정 안정성: 유지
- 합법성: 완벽

### 위험 요소:
- 부모님과 동거 중이면 효과 없음
- 형식적 분리는 추징 위험
- 형제자매 있으면 상속 시 고려 필요

## 최종 결론

**부모님께 증여가 최적의 해결책**

**조건:**
- 부모님이 실제로 별도 거주 중이어야 함
- 실질적 세대 분리 상태여야 함

**효과:**
- 2억 주택 처분 문제 해결
- 3~5억원 세금 절감
- 합법적이고 안전함
- 가정 안정성 유지

**반드시:**
- 세무사와 정확한 시뮬레이션
- 1가구 판정 여부 확인
- 안전한 방법으로 진행
