# 업무-관리 마스터

업무-관리/ 디렉터리는 Weekly 주간 계획 노트와 그때그때 발생한 업무 이슈(클레임, 정책 변경, 미팅 기록 등)로 구성된다. 이 페이지는 두 Weekly 노트의 반복 패턴·열린 액션 아이템과, 별도 이슈/미팅 노트 3건의 핵심 사실을 종합한다.

## Weekly 노트 운영 패턴

- **구조**: 캘린더 → Top 3 목표 → 프로젝트별 To-Do(Sinokor / HMM Tenglong 또는 Pan Ocean / Polaris-Glovis / WorkBrain·Second Brain·커리어) → 일별 링크 → 주간 Review(금요일 EOD 작성) 순으로 고정된 템플릿을 따름 (`Weekly-템플릿.md` 참조).
- **프로젝트 트랙 변화**: W17(4월)에는 "HMM Tenglong"이 트랙으로 있었으나 W25(6월)에는 빠지고 "Pan Ocean"이 새 트랙으로 들어감 — 영업 우선순위가 바뀐 것으로 보임. Sinokor, Polaris/Glovis는 두 주 모두 공통 트랙.
- **실제 기록 상태**: 두 Weekly 노트 모두 Top 3 목표, 프로젝트별 To-Do, Review 섹션이 **거의 비어 있음**(체크박스만 있고 내용 없음). 실질적으로 채워진 것은 W17의 캘린더(Monthly Tanker Tribunal, MMS Project Update Meeting)와 W17/W25의 "lint 실행" 액션 아이템 정도.
- **lint 알림 패턴**: W25는 "마지막 lint: 2026-06-04 — 17일 경과, 이번 주 중 lint 실행 권장" 경고를 본문에 남김. `.claude/rules/lint-routine.md`의 7일 경과 알림 트리거가 실제로 작동한 사례.
- **재개**: W25(6/21 종료) 이후 약 4개월 끊겼던 Weekly 노트를 2026-W43(10/19~10/25)부터 재개. 재개 계기는 2026-10-22 lint에서 공백이 발견된 것 — Polaris class fee 협상 후속 확인을 첫 To-Do 항목으로 이어서 반영함.

- [ ] (W17) Second Brain wiki 첫 ingest 테스트 — 완료 여부 불명, 후속 노트에 언급 없음
- [ ] (W17, W25) lint 실행 — 두 주 모두 체크 안 됨. W25 기준 lint 자체가 17일 밀려 있었음
- [ ] Sinokor / Polaris-Glovis 프로젝트별 To-Do — 두 주 모두 빈 체크박스뿐, 실제 작업 내용이 기록된 적 없음

## 핵심 이슈 1 — BV WebRisk → TrustFlow 전환 (2026-06-22 기록)

- WebRisk(스폰서십·CSR·위원회·선물 등 모든 요청) **사전 승인 의무화** — M&O President Alex Gregg-Smith 결재 필수, 미승인 시 자동 반려.
- 스폰서십/기부는 연간 **3~4건 한도**(지역 SVP 재량 예외 가능, 승인 시 "예외 항목임" 명기 필요).
- 시스템 전환: 2026년 **7월 중순** WebRisk → TrustFlow (기능 변화는 크지 않음).
- 행사 임박 신청은 사실상 승인 불가 — 조기 신청이 핵심.
- **미확인 후속 액션**: 하반기 고객사 행사 후원 계획 시 SVP Jeffrey Guo 통한 사전 승인 요청, TrustFlow 전환 후 계정/접근 변경 여부 확인, 예외 항목 코드 기재 방법 확인 — 이 3가지는 노트 작성 이후 진행 상황이 기록된 곳이 없음 (전환 시점인 7월 중순이 이미 지남, 10월 현재 확인 필요).

## 핵심 이슈 2 — Sinokor 2800TEU 컨테이너선 Lashing 클레임 (2026-06-22 기록)

- **쟁점 1**: KR(한국선급)과 BV의 lashing 계산값 불일치. 다음 미팅에서 동일 twistlock gap(수평/수직) 적용해 재비교 예정이었고, BV는 Bay38 상갑판 처짐값(deflection) 계산 제공을 요청받음.
- **쟁점 2**: Lashing bridge 설치 선박의 CSS Code 비준수는 case-by-case 검토, 명확한 위반 시 Liberia Flag 당국 면제(exemption) 취득 필요.
- 담당: BV 대응 Young-Jun SEO, 보고 라인 Ki-Soo HUH(BV Korea), 본인(한상진)은 CC 수신·모니터링 역할.
- **미확인 후속 액션**: 공동 미팅 일정·Bay38 deflection 결과, Liberia Flag exemption 신청 결과, 클레임 해결 후 Sinokor 관계 복원 미팅 기회 — 세 건 모두 노트 작성(6/22) 이후 업데이트가 이 디렉터리에 없음.

## 핵심 이슈 3 — Polaris Shipping VLOC(4×210K Ore Carrier)·VLEC 신조 BV 선급 미팅 (2026-07-30 기록)

- 칭다오 베이하이 조선소 4×210K Ore Carrier(Newcastlemax) 신조 — 건조 단계 DNV 리드 + BV 50:50 Dual Class, 인도(2031년 예정) 후 BV 단독(Single Class) 전환 협상. 연간 class 비용은 Single $20K/Dual $15K로 BV 제시했으나, Polaris는 임시검사 비용 포함 + KR 이하 수준을 요구.
- Polaris는 칭다오 조선소에 BV 소속 한국인 서베이어 상주를 요청 — BV는 1.25배 비용 할증 포함 파견 비용을 산정해 프랑스 본사(Mustafa, 재무팀)와 타당성 검토 중.
- 병행 프로젝트: 한국 최초 미국산 에탄올 VLEC(한화오션, GTT NO96 검토), 정부 규정·Citadel 리스트는 DNV에 전달 예정.
- Polaris와 HMM이 동일 선형·사양으로 공동 추진 중 — Polaris의 선급 결정이 HMM 선택에 영향을 미침. 상세: [[polaris-vloc-vlec-신조-미팅]].
- **미확인 후속 액션**: 한국인 서베이어 파견 비용 본사 검토 결과, KR 이하 class fee 비교안 제출 여부, 한화오션·HMM 공동 사양 회의 일정 — 모두 7/30 기록 이후 후속 업데이트가 이 디렉터리에 없음.

## 미반영/추가 필요

- **Weekly 노트 공백 심각**: W17(4/19~4/25), W25(6/15~6/21) 둘 다 핵심 내용(목표, 프로젝트 To-Do, Review)이 비어 있어 실제 업무 흐름 파악에 한계가 있음.
- **Weekly 노트 작성 주기 단절 → 재개**: W25(2026-06-21 종료) 이후 약 4개월 끊겼다가 2026-W43(10/19~)부터 재개됨. W26~W42 구간은 기록이 없는 공백으로 남음.
- **bv-webrisk-trustflow, sinokor-lashing-claim 둘 다 6/22 기록 이후 업데이트 없음**: TrustFlow 전환(7월 중순) 완료 여부, Sinokor 클레임 진행 상황(미팅 결과, exemption 결과) 등 실제로는 진행되었을 가능성이 높은데 이 디렉터리에는 후속 기록이 없음. 사용자 확인 후 두 페이지 자체를 업데이트하거나 `해운-영업/` 쪽에 후속 노트를 만드는 것을 권장.
- **lint 실행 이력 공백**: W25 노트상 마지막 lint가 2026-06-04로 기록된 이후, 이 디렉터리 안에서는 lint 실행 여부를 확인할 자료가 없음.
