# INGEST — 원재료 소화 커맨드

raw/ 폴더의 새 파일을 읽어 wiki/ 페이지로 컴파일한다.

## 실행 전 준비

### Step 0: 시스템 파일 확인
반드시 먼저 읽는다:
```
10. 개인 지식 관리 시스템.  Second Brain./CLAUDE.md          ← 시스템 규칙 확인
10. 개인 지식 관리 시스템.  Second Brain./wiki/_Index.md     ← 현재 위키 페이지 목록 파악
```

### Step 1: Raw 파일 탐색
```
10. 개인 지식 관리 시스템.  Second Brain./raw/               ← 전체 raw 폴더 스캔
```
- 처리되지 않은 파일 식별 (frontmatter에 `ingested: true` 없는 것)
- 사용자가 특정 파일을 지목했으면 그것만 처리

## 처리 로직

### Step 1.5: Vault 라우팅 판단 (ingest 전 필수)
파일을 읽기 전에 **이 vault(Second Brain) 소속인지 먼저 판단**한다.

- 해운 업계 동향, 고객사, BV 영업 관련 → **WorkBrain으로 라우팅** (처리 중단, 사용자에게 알림)
- 두 vault 모두 해당하는 브리지 인사이트 → Second Brain에 처리 후 WorkBrain 참조 메모 추가
- 나머지 → 이 vault에서 처리 계속

### Step 2: 파일 분석
각 raw 파일을 읽고 다음을 파악:
- **주제 분류**: 어느 wiki 카테고리에 해당하는가?
  - `나-자신/` — 개인 경험, 사고방식, 감정, 실패, 성장
  - `AI-생산성/` — AI 도구, 워크플로, 실험, 인사이트
  - `커리어-전환/` — 관세사, 2nd career, 자격증, 투자 전략
- **핵심 엔티티**: 사람 이름, 회사명, 프로젝트명
- **핵심 인사이트**: 배운 것, 결정, 패턴
- **연결 가능한 기존 페이지**: `_Index.md` 기준으로 확인

### Step 3: Wiki 페이지 결정
- 기존 페이지에 추가할 내용인가? → 해당 페이지 append
- 새 페이지가 필요한가? → 아래 템플릿으로 신규 생성

### 신규 페이지 템플릿
```markdown
---
updated: YYYY-MM-DD
tags: [태그1, 태그2]
related: [[관련페이지1]], [[관련페이지2]]
source: raw/[원본파일명]
---

# 페이지 제목

## 핵심 내용

## 배운 것 / 인사이트

## 관련 컨텍스트

## 미해결 질문
```

### Step 4: 위키링크 연결
- 새로 생성된 페이지에서 기존 페이지로 `[[링크]]` 추가
- 관련 기존 페이지에서 새 페이지로 역링크 추가
  (기존 페이지 하단 "관련 페이지" 섹션에 추가)

### Step 5: Raw 파일에 처리 완료 표시
처리가 끝난 raw 파일 frontmatter에 추가:
```yaml
ingested: true
ingested_date: YYYY-MM-DD
wiki_pages: [생성/업데이트된 페이지 목록]
```

### Step 6: _Index.md 업데이트
```
10. 개인 지식 관리 시스템.  Second Brain./wiki/_Index.md
```
- 새 페이지 → 테이블에 행 추가
- Raw 파일 목록 → 처리된 파일 추가
- 통계 → 페이지 수, raw 파일 수, 마지막 ingest 날짜 갱신

## 결과 보고
완료 후 사용자에게 보고:
```
✅ INGEST 완료
- 처리한 raw 파일: N개
- 생성된 wiki 페이지: [목록]
- 업데이트된 wiki 페이지: [목록]
- 추가된 위키링크: N개
```

## 품질 기준
- 위키 페이지는 최소 3개 이상의 문장으로 작성 (stub 금지)
- 모든 페이지는 최소 1개 이상의 `[[위키링크]]` 포함
- 인사이트와 원본 사실을 구분해서 기록
- 개인적 판단/감정은 "배운 것/인사이트" 섹션에만 기록
