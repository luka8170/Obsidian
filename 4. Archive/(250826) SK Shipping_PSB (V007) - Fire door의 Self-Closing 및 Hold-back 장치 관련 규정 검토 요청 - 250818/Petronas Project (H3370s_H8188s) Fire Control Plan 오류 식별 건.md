
# 🛠 Petronas Project (H3370s/H8188s) Fire Control Plan 오류 식별 건

- 2025년 8월 20일 안전운항팀 측으로부터 PUTERI SABAH 선박의 Fire Control Plan 점검 사항 검토 요청 접수  
  (첨부: *FW: [Safety] - PSB (V007) - Fire door의 Self-Closing 및 Hold-back 장치 관련 규정 검토 요청 - 250818*)

- PTE 선박 → 인도 전 조치 예정  
  (첨부: *RE: [Safety] - PSB (V007) - Fire door의 Self-Closing 및 Hold-back 장치 관련 규정 검토 요청 - 250818*)

## 2. 향후 대책
- 도면과 현장 간 불일치 관련 → 선급 검사 품질 VOC 전달
- **New Building Circular** 작성 → 향후 신조선 건조 시 조선소 측 전달

---

## 3. R&R
- 도면에는 Rule 요구 항목만 반영됨 → 편의상 추가한 Self-closing 장치는 도면 상 미반영  
- **2-deck 이상 연결 공간의 A-class door** → Hold-back unit 미적용  
- **SOLAS Reg.II-2/9.4.2.2**  
  > 자기폐쇄형이 요구되는 문에는 개방 고정용 후크를 설치하여서는 아니 된다.  
  > 다만, 고장방지형 원격 해제장치를 갖춘 개방고정장치(hold-back arrangements fitted with remote release devices of the fail-safe type)는 사용할 수 있다.

  (첨부: *H8188 Fire door 점검 보고서*, *H8189 Fire door 점검 보고서*)
