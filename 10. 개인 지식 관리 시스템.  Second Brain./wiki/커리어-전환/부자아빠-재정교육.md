# 부자 아빠 가난한 아빠 — 기요사키

## 핵심 내용

부자 아버지(친구 아버지, 사업가)와 가난한 아버지(친부, 고학력 공무원)의 돈에 대한 상반된 교훈 비교.

## 핵심 교훈 5가지

1. **부자는 돈을 위해 일하지 않는다**
   - 가난한 사람: 돈 → 노동 (무한반복)
   - 부자: 돈이 자신을 위해 일하도록 자산 구조 설계

2. **저축하는 사람은 패배자가 된다**
   - 인플레이션이 저축의 실질 가치를 갉아먹음
   - 저축 → 투자 자산(부동산, 주식, 사업)으로 전환 필요

3. **자산 vs 부채의 구분**
   - **자산**: 주머니에 돈을 넣어주는 것 (임대 부동산, 배당주, 사업 수익)
   - **부채**: 주머니에서 돈을 빼가는 것 (대출, 차, 자가 거주 주택)
   - 핵심: 자산 칼럼을 키워라

4. **세금은 회사를 통해 줄인다**
   - 법인 → 비용 처리 후 세금 → 개인에게 분배
   - 개인 → 세금 먼저 → 남은 돈으로 생활
   - 자영업/법인 구조 활용의 중요성

5. **현금흐름 사분면 (ESBI)**
   - E(Employee) → S(Self-employed) → B(Business) → I(Investor) 순으로 이동 목표

## Luka 적용

- 현재: E(BV 피고용인) 포지션
- 목표: B(물류 플랫폼 사업) + I(부동산/투자) 포지션으로 이동
- 관세사 취득은 S(전문직) 레인 추가로 E 의존도 감소가 먼저

## 적용 액션

- [ ] 현재 월 현금흐름 자산/부채 분류 → 자산 칼럼 비중 확인
- [ ] 분당 자가 주택 → 자산인가 부채인가? 활용 방안 검토
- [ ] 법인 설립 타임라인과 세금 효율화 시나리오 검토
